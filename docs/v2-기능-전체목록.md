# 오직 트레이너 기능 전체 목록 (2026-10-12 · 코드 기준)

- 앱 화면 4갈래(트레이너 · 대표 · 회원 전용 페이지 · 공개 페이지)를 코드에서 직접 읽어, 버튼 · 카드 · 안내 문구 단위로 정리했어요.
- 영역은 8개예요: 화면 5개(트레이너 / OT · PT 회원 · 세일즈북 / 대표 / 회원 전용 페이지 / 공개 · 가입 · 결제) + 자동으로 도는 일 + AI가 하는 일 + 안 쓰이는 것 · 빈 곳.
- 화면 기능 줄은 약 1,120줄이에요(1장 221 · 2장 439 · 3장 194 · 4장 146 · 5장 117).
- 네 갈래를 따로 읽은 보고서 4개를 합쳤고, 두 보고서에 똑같이 나온 줄은 한 번만 남겼어요(예: 로그인 · 404 · 이벤트 관리 · 구독 관리).
- 보고서를 쓴 뒤 고쳐진 것(공지 창 닫기 · 대표 체크리스트 탭 이동 · 넓은 화면 회원 목록 묶음 · 재등록 세일즈북 트레이너 정보)은 고친 모습으로 적었어요.
- 안 쓰이는 코드 · 문제 · 확인이 필요한 것은 기능 줄에 섞지 않고 8장에 모았어요.

## 1. 트레이너 화면

### 공통 앱 틀 (로그인 · 게이트 · 메뉴 · 설치 · 공지 · 오류)
- 앱을 처음 열면 세션을 확인하는 동안 "불러오는 중…"이 떠요. 8초가 넘으면 "네트워크가 느리거나…" 안내와 [다시 시도] 버튼이 나와요.
- 로그인한 채로 /login에 가면 홈(/)으로 보내요. 로그아웃 상태에서 /에 오면 공개 랜딩 페이지가 보여요.
- 로그인 없이 열리는 주소: 회원 페이지(/m), /lp, /center, /download, /legal, /join/…, /try, /check, /reset-password, /signup.
- 로그인 상태면 결제 착지(/billing/*), 옛 /join-center/*, /leave-center는 잠긴 계정이어도 열려요.
- 임시 비밀번호로 처음 로그인하면 전체 화면 "임시 비밀번호 변경"을 꼭 거쳐야 해요(6자 이상, 확인 칸 일치 검사).
- 구독 상태를 확인하는 동안 "불러오는 중…"이 떠요. 조회가 실패하면 잠그는 쪽으로 처리해요.
- 대표가 끈 트레이너 아이디(TrainerOff): "센터에서 이 아이디를 껐어요" 안내, 남은 보관 날짜, [개인으로 가입하기](로그아웃 뒤 /signup), [로그아웃].
- 결제벽(Paywall): 상태별 제목 3가지(계정 준비 중 / 이용 기간이 끝났어요 / 구독하고 시작하세요).
- 결제벽 요금제 고르기: 개인 계정은 프로(추천) · 베이직, 센터 계정은 센터만. 금액 · 설명 · 추가 자리가 반영되고, 랜딩에서 고른 요금제가 기본으로 선택돼요.
- 결제벽 [카드 등록하고 시작하기 / 이어서 이용하기]는 토스 카드 등록창을 열어요. 아래에 "부가세 포함 · 오늘 ○원 결제 · 7일 안 전액 환불 · 언제든 해지" 안내가 있어요.
- 결제벽에서 센터 소속 트레이너에게는 결제 대신 "대표에게 알려 주세요"만 보여요. 센터에서 독립한 계정은 "개인 계정 카드 등록" 문구가 나와요.
- 결제벽 아래 [다시 로그인]. 읽기 전용 상태에서 연 결제벽이면 [돌아가기(볼 수만 있는 화면)].
- 읽기 전용 30일 띠: 맨 위 빨간 띠에 "○월 ○일까지 볼 수만". 대표에게는 [내 데이터 내려받기](진행 메시지, 못 받은 사진 수) · [카드 등록하고 다시 쓰기], 센터 트레이너에게는 "대표에게 알려 주세요".
- 데모 모드(키 없음): 게이트 없이 앱이 열리고, 위에 "데모 모드예요…" 안내 띠가 떠요. 회원은 비어 있고, 신규 등록은 "Supabase가 아직 설정되지 않았어요"로 막혀요.
- 회원 목록을 불러오지 못하면 껍데기 위에 오류 띠가 떠요("불러오지 못했어요…").
- 폰 헤더: 로고 + 트레이너 이름(누르면 홈), 공지 종(안 읽은 수 빨간 원 · 개인 계정은 숨김), 센터 대표만 "대표 화면" 버튼(/admin).
- 폰 하단바 5칸(홈 · 오늘 · 회원 · 내 실적 · 설정). 터치 영역 52px, 지금 있는 칸 강조.
- 태블릿 · PC 왼쪽 세로 메뉴: 홈 · 오늘 · 회원 · 내 실적 · 세일즈북(넓은 화면 전용) · 설정 + 아래에 공지 · 대표 화면. 1280px 이상이면 로고 · 이름이 가로로 펼쳐져요.
- 세일즈북 화면 헤더에는 위 칸 탭 "발표 자료 | 사례 보관함"이 있어요.
- 넓은 화면(1024px 이상) 회원 · OT · PT 화면은 2단이에요(왼쪽 회원 목록 + 오른쪽 본문). [목록 접기] / [회원 목록]으로 펼치고 접고, 이 상태는 이 기기에 기억돼요.
- 화면을 옮길 때마다 본문 진입 모션이 다시 재생돼요. 화면을 준비하는 동안 스켈레톤(회색 틀 카드 3장)이 보여요.
- 필수 확인 공지가 있으면 앱 전체를 덮는 창("필수 확인 공지" + 개수)이 떠요. 바깥을 누르거나 ESC로 닫히지 않고, [확인했습니다]를 눌러야 닫혀요.
- 공지 종을 누르면 받은 공지 전체가 열려요(고정 핀 표시 · 필수확인 배지 · 읽은 것은 흐리게). 열면 일반 공지는 읽음 처리돼요. 이 창은 ✕ · 바깥 누르기로 닫혀요(필수 확인 공지 창만 [확인했습니다]로 닫혀요).
- 공지 대상: 전체 공지, 또는 내가 대상인 공지만 보여요. 내가 쓴 공지는 빠지고, 고정 공지가 먼저 · 그다음 최신순이에요.
- 화면 오류가 나면 "문제가 발생했어요" + 오류 코드 + [다시 시도] [처음으로]. 앱 전체가 깨지면 최소 화면 + [다시 시도].
- 잡히지 않은 오류 · Promise 실패는 화면에 아무것도 보이지 않고 서버로 자동 보고돼요.
- 홈 화면 추가 안내(폰 홈 맨 위, 한 번만): 아이폰은 방법 글, 안드로이드는 [홈 화면에 추가] 버튼, 닫으면 다시 안 떠요. 이미 설치했거나 PC면 안 보여요.
- 공유 미리보기(카톡 · 검색 OG 이미지), 검색 사이트 소유 확인, 아이폰 웹앱 메타(스플래시용 태그 수동 복원)가 들어가 있어요.
- 글꼴: 본문 Pretendard, 숫자 Geist Mono, 세일즈북 서명 · 다짐은 손글씨(나눔펜).

### 폰 홈 (TrainerHub)
- 인사: 날짜 · 요일 + "○○ 트레이너님"(이름이 없으면 "오늘도 반가워요").
- 처음 시작하기 체크리스트는 가입 30일 안 아이디에만 보여요.
  - 계정 종류별 줄: 센터 대표 / 개인(프리랜서는 장부 줄 추가) / 센터 소속.
  - "첫날 10분" → 다 끝나면 "첫 주"가 펼쳐져요. 진행 막대, "AI가 더 정확해져요" 표시가 있어요.
  - 기록을 읽어 끝난 줄은 자동으로 줄이 그어지고, 안 한 줄은 [하러 가기] 링크예요.
  - [나중에 하기]로 한 줄로 접히고(이 기기 기억), 다 끝나면 축하 한 줄이 하루만 보여요.
- 오늘 카드(고정): 오늘 수업 N건(완료 · 남음), 오늘 신규 OT N명(이름), [스케줄 ›].
- 오늘 카드의 다음 수업 큰 버튼: OT면 "OT 준비하기", PT면 "회원 자료 보기". 시작 30분 지난 수업까지 다음 수업으로 잡아요.
- 그 아래 있을 때만 뜨는 카드: 월간 결산 준비 · 새 OT 회원 · 수업 요청 · 대표 피드백 · 급여 확정 · 루틴 요청 · 기본정보 마무리 · PT 종료.
- 바로가기 칸(2열, 640px 이상이면 4열). 기본은 OT 회원(명수) · PT 회원(명수) · 세일즈북 · 내 실적.
- 바로가기 칸 추가 후보: 스케줄 · 사례 보관함 · PT 가격표(누를 때 패키지를 읽어 가격표 창) · 신규 회원 등록.
- 정보 카드: 기본은 오운완 랭킹. 후보는 이번 달 내 숫자 · 재등록 타이밍 · 이탈 위험 · 운동일지 확인 요청 · OT 다시 연락할 회원 · 인바디 잴 회원. 대상이 없으면 카드가 숨어요.
- [홈 편집]: 칸 · 카드를 위로 · 아래로 · 빼기, "추가할 수 있어요" 칩으로 넣기, [처음 구성으로 되돌리기], [완료]. 이 기기에만 바로 저장돼요.
- 하단: [신규 회원 등록](칸에 없을 때), [종료 회원 N명], [홈 편집].
- 범위: 내 담당 회원만. 직접 맡은 회원이 없는 대표는 센터 전체를 봐요.
- 이번 달 내 숫자 카드: 신규 등록 · 재등록 건수 · 매출(만원), [내 실적 ›]. 데모에선 숨어요.
- 오운완 랭킹 카드: "이번 달 | 연속일" 전환, 상위 5명 + [더 보기 · N명](최대 10명).
  - 1~3위 강조, "N일 연속" 표시, 누르면 그 회원 화면, 아래에 "오운완 = …" 설명.
  - 이번 달 기록이 0이면 카드가 숨어요.

### 넓은 홈 (WideHome, 1024px 이상 · 고정 · 편집 없음)
- 인사 "○○님, 오늘 할 일이에요". 센터 전체를 볼 때는 그 안내가 붙고, [스케줄 전체 보기 →] 링크가 있어요.
- 처음 시작하기 체크리스트(폰과 같음).
- 숫자 4칸: 오늘 수업 · 오늘 신규 OT(이름) · 운동일지 확인 대기(명/건) · 회원 페이지 새 기록(최근 3일 명수).
- 1열 "오늘 일정": 시간 · 이름 · OT/PT 배지 · 완료 체크. 지났는데 완료 안 한 수업은 빨간 시간이고, OT는 준비 화면으로 연결돼요. 아래에 메모 할 일.
- 2열 "오늘 챙길 회원": 결산 준비 · 새 OT 회원 · 수업 요청 · 대표 피드백 · 급여 확정 · 루틴 요청 · 기본정보 마무리 · 오늘 재접근 · 재등록 타이밍 · 재등록 재접근 · PT 종료 · 클로징 미마감 · 이탈 위험 · 인바디 잴 회원. 맨 아래 "해당하는 회원이 있을 때만 카드가 떠요".
- 3열 "회원 쪽 소식": 운동일지 확인 대기(회원별 미확인 N건, 최대 6명), 회원 페이지 새 기록(유산소 · 사진 · 개인운동, 최근 3일, 최대 6명, "오늘/어제/N일 전"), 오운완 랭킹, 다음 예약 미정(5명 + "외 N명"), 미처리 예약.

### 오늘 탭 (/today, 카드마다 한 줄)
- 회원 목록을 불러오기 전에는 "불러오는 중…", 회원이 0명이면 "첫 회원을 등록해 시작해요" + [첫 회원 등록하기].
- 배치: 넓은 화면은 왼쪽 스케줄 | 오른쪽 이탈 위험 · 할 일, 폰은 위아래 한 줄.
- 이탈 위험: 남은 수업이 있는데 14일 넘게 안 온 내 PT 회원("N일째 수업 없음 / 등록 후 N일째 안 옴 · 남은 N회") → 회원 대시보드로.
- "오늘 할 일" 제목과 설명 한 줄.
- 월간 결산 카드: 매월 1~10일, 안 열어 본 지난달 성적표 · 결산이 있으면 한 줄 → 내 실적으로.
- 새 OT 회원: OT 신청서로 들어온 회원.
  - 표시: 내 QR / 대표 배정 / 이미 있는 회원 재신청, 몇 분 전, 원하는 시간.
  - 누르면 OT 화면으로 가면서 확인 처리돼요. [확인]만 눌러도 사라지고, 새 회원이 목록에 없으면 목록을 다시 불러와요.
- 수업 요청: 회원이 보낸 새 수업 · 시간 변경 · 취소 요청(요청 시각, 회원 메모).
  - [승인] = 스케줄에 바로 반영 · 스케줄 다시 읽기 · 회원 폰 알림.
  - [거절] = 한마디(선택) 입력 후 거절.
  - 같은 시간 충돌 · 이미 바뀐 예약이면 안내가 떠요.
- 대표 피드백: 날짜 · 건 종류 · 본문(회원 이름을 누르면 회원 화면) · [확인했어요]. 다음 대본에 반영된다는 안내가 있어요.
- 급여가 확정됐어요: ○월 급여 금액, 달마다 바뀌는 격려 문장, [내역](→/stats), [확인했어요].
- 루틴 요청: 회원이 개인운동 루틴을 요청함("오늘 요청 / N일째 기다림") → 케어 탭.
- 기본정보를 마무리해 주세요: 회당 단가가 빈 PT 회원은 카드 안에서 단가를 바로 저장, 휴대폰이 빈 회원은 [휴대폰 넣기 · 정보 수정] 창.
- 식단(오늘 탭에만 있음):
  - 식단 요청("N분 뒤 AI / 곧 AI / 직접 답하기").
  - 오늘 식단 끝 → 하루 피드백("오전 6시 AI").
  - 어제 AI가 보낸 피드백("한마디").
  - 어제 피드백이 아직 안 나감("직접 보내기"), 기록 3일째 끊김.
  - AI 한도를 다 쓰면 "AI 한도 끝 · 직접 답하기"로 바뀌어요. 누르면 케어 탭 식단 창이 바로 열려요. 열 때 AI 대신 보내기 작업을 한 번 실행해요.
- 오늘 재접근: 보류 · 다음 OT로 미뤘던 OT 회원 중 연락할 날이 된 회원(예정일, "N일 경과/오늘", N차) → 1차 OT.
- 재등록 타이밍: 남은 유료 수업 10회 미만(잔여 유료 · 서비스) → 재등록 탭.

### 스케줄 (ScheduleBoard)
- [오늘 | 주간] 전환. 폰(640px 미만)은 처음에 오늘 보기예요.
- 대표 화면(트레이너가 여럿 보일 때): [전체 트레이너] 고르기, 트레이너별 색 범례, 칩 색 · 이름 · 왼쪽 색 띠.
- 주간: "M/D ~ M/D", [‹] [이번 주] [›], 보이는 시간 범위 시작(0~12시) · 끝(13~24시) 고르기.
- 주간 표: 요일 · 날짜 머리줄. 일요일 · 공휴일은 빨강, 토요일은 파랑. 공휴일 이름(2026년 표만 들어 있음)과 하루 종일 일정 칩이 머리줄에 보여요.
- 칸마다 예약 칩: 회원 상태 색점 · 이름 · 30분 시작 표시 · 완료는 "✓"와 줄 긋기. 대표 화면에서 전체 보기면 트레이너 이름이 붙어요.
- 개인 일정은 점선 칩으로 보이고, 여러 칸에 걸치면 "↳ 제목"으로 이어져요. 빈 칸에는 + 표시가 있어요.
- 빈 칸을 누르면 창: [회원 수업 | 개인 일정].
  - 회원 수업: 시작 :00/:30 고르기(수업 1시간), 회원 검색, OT 신청서에 적은 "원하는 시간"과 맞는 회원이 위에 배지와 함께 떠요. 회원을 누르면 바로 예약돼요.
  - 대표가 잡아도 그 회원의 담당 트레이너 예약으로 들어가요.
- 오늘 보기: 날짜 · "남은 수업 N개", 하루 종일 일정 → 시간 순 수업 · 개인 일정 목록. 없으면 "오늘 예약이 없어요."
- PT 예약을 누르면 창: [회원 정보] 바로가기.
  - [🎙 음성으로 채우기](음성일지로 내용 채우기), 수업 내용 입력.
  - [완료 · 차감(· 카톡 복사)]: 내용을 클립보드에 복사, 운동일지 만들기, 회원 폰 알림.
  - [완료 · 차감 안 함(보강 · 무료)], [예약 취소].
  - 남은 계약이 없으면 "차감하지 않았어요. 계약을 먼저 등록해 주세요".
  - 같은 날 이미 써 둔 운동일지가 있으면 그 일지와 연결해서 두 번 빠지지 않게 해요.
- OT 예약을 누르면 창: [OT 준비 열기](진행 차수에 맞는 화면으로), [수업 완료](차감 · 일지 없음), [예약 취소].
- 이미 완료한 예약을 누르면 "완료한 수업이에요"만 떠요.
- 개인 일정 만들기 · 고치기:
  - 제목 + 빠른 칩(회의 · 청소 · 휴무 · 교육 · 점심 · 개인 운동, 휴무는 자동으로 하루 종일).
  - 색 6가지, 날짜, 하루 종일, 시작 · 끝 30분 단위.
  - 반복: 안 함/매일/매주(요일 여러 개)/매월 + 끝나는 날.
  - 시간 · 날짜 순서를 검사해요.
- 내 개인 일정을 열면 고치기 · [이 날만 빼기](반복일 때) · [반복 전체 삭제/삭제]. 남의 일정(대표가 볼 때)은 보기만 돼요.
- 다른 카드(수업 요청 승인 등)가 예약을 바꾸면 스케줄을 다시 읽어요.

## 2. OT · PT 회원 화면 · 세일즈북

### 회원 화면 공통 (머리 · 상태 분기 · 지난 회원 · 환불 · 회원 페이지 링크)
- 주소가 둘로 나뉨: `/ot/{회원}`은 OT 대시보드, `/ot/{회원}/{prep|inbody|feedback}-{n}`은 n차 화면, `/pt/{회원}/{logs|write|care|renewal}`은 PT 화면.
- 주소의 OT/PT와 회원의 실제 상태가 다르면 맞는 주소로 자동으로 옮김 (예: 등록 확정 직후).
- 없는 회원(삭제 · 환불 · 남의 링크)으로 들어오면 회원 목록으로 돌려보냄. 첫 조회가 끝나기 전에는 판단하지 않고 빈 틀(스켈레톤)을 보여 줌.
- 데모 모드(키 없음)에서는 예시 회원으로 화면이 열림.
- 회원 상태에 따라 OT 화면 / PT 화면(따로 늦게 불러옴) / 지난 회원 화면으로 갈림.
- OT 회원이 어느 차수에서든 '클로징 성공'으로 기록돼 있으면 'PT 등록 확정' 배너가 뜸. 성공을 기록해도 자동으로 등록되지 않는다는 안내가 같이 있음.
- 등록 확정 창: 세션 수 · 회당 단가는 꼭 입력, 총액은 자동 계산(고칠 수 있음), 서비스 세션 입력. [확정]을 누르면 PT 회원이 되고 계약이 생김. 회원을 바꾸면 입력값이 지워짐.
- 클로징을 저장하면 배너가 바로 다시 확인함(closingVersion).
- 지난 회원 화면에서 할 수 있는 것:
  - '회원 목록'으로 돌아가기.
  - 'N년 N월 N일에 PT를 마쳤어요'와 종료 메모를 봄.
  - [다시 PT 시작하기]: PT 회원으로 돌아가고 기록은 그대로 이어짐. 'PT 종료' 알림은 7일 미뤄짐.
  - 회원 전용 페이지 상태 안내: 꺼짐 / 6개월이 지나 닫힘 / 'N월 N일까지 볼 수만 있어요'.
  - 링크가 남아 있으면 '볼 수만 있음' 배지와 [링크 복사] · [회원 페이지 끄기].
- 지난 회원만 위쪽에 [정보 수정] 버튼이 따로 있음. OT · PT 회원은 대시보드 회원 카드 안에 있음.
- 환불(자료남기기 탭 맨 끝, 접힘):
  - 대상은 가장 최근의 유료 계약이고, 금액 · 날짜를 보여 줌.
  - 환불 금액을 입력하는데 계약 금액보다 크면 막음.
  - 버튼을 두 번 눌러야 처리됨('정말 환불·삭제할까요?').
  - 처리하면 환불 기록이 남고, 회원이 숨겨지고(사실상 삭제), 회원 목록으로 돌아감.
  - 유료 계약이 없으면 버튼이 꺼짐. 데모 모드에서는 쓸 수 없다는 안내가 뜸.
- PT 기록을 불러오지 못하면 안내와 [다시 불러오기]가 뜸. 빈 기록으로 착각해 재등록이 '신규'로 저장되는 것을 막기 위함.
- 회원 전용 페이지 링크:
  - [링크 생성]: 서버가 플랜을 확인한 뒤 링크를 만들고 바로 복사함. 프리미엄이 아니면 안내가 뜸.
  - 배지로 '발급됨'(아직 안 들어옴) / '연결됨'(회원이 한 번 이상 로그인)을 구분.
  - [링크 복사]: 복사가 안 되면 길게 눌러 복사하라는 안내.
  - [회원 페이지 끄기]: 확인을 한 번 더 받은 뒤 회원 세션을 끊고 링크를 없앰. 기록은 남음.
  - 데모 모드에서는 실제로 만들거나 끄지 않는다는 안내가 뜸.

### OT 대시보드
- 탭 두 줄. 윗줄은 대시보드 | 1차 OT | 2차 OT …, 차수를 고르면 아랫줄에 OT 준비하기 | 인바디 분석 | OT 피드백.
- 차수 탭을 누르면 그 차수에서 아직 안 한 첫 칸으로 감.
- 다음 차수를 열 수 있을 때는 탭 옆에 점선 '+N차 OT' 버튼이 생김.
- 열 수 없는 차수 주소나 차수가 빠진 주소는 지금 차수로 바로잡음. 기록을 못 읽었을 때는 바로잡지 않고 '다시 불러오기' 안내를 띄움.
- 회원 카드:
  - 이름 두 글자 원, 이름, 상태 배지('OT · N차 진행 중' / '등록 완료' / 'OT 종료').
  - 나이 · 직업 · 사는 곳 · MBTI, [정보 수정].
  - 목표 · 불편 부위.
  - 신청서의 건강 체크 내용이 있으면 빨간 줄로 보임.
  - 운동 가능 횟수(주 몇 번) · 알게 된 경로.
  - 원하는 시간(요일 · 시간 묶음, 없으면 예전 글).
- '아직 몰라요': 1차 전에 빠진 칸(목표 · 주 몇 번 · 운동 경험 · 그만둔 이유 · 건강 상태)을 보여 주고, 1차 대본이 첫 5분 질문으로 채워 준다고 안내.
- 숫자 칸:
  - 최근 OT: 날짜와 'N차 · 결과'.
  - 다음 OT 예약: 오늘/내일/날짜. 오늘이면 빨갛게 표시하고, 예약이 없으면 '스케줄에서 잡아 주세요'.
  - 인바디: 체중 · 골격근 · 체지방, 측정 횟수. 누르면 인바디 분석 칸으로 감.
- '지금 할 일' 빨간 버튼: 지금 차수에서 아직 안 한 칸(준비하기 또는 피드백)으로 감.
- 'OT 진행' 목록: 차수마다 준비 ✓ · 피드백 ✓, 결과 배지(등록/보류/실패/이어가기/결과 미기록), 지금 차수에는 '지금' 표시. 누르면 그 차수로 감.
- [N차 OT 시작]: 마지막 차수의 피드백까지 남겼고 등록이나 실패가 아닐 때만 보임.
- 넓은 화면(회원 칸 768px 이상)에서는 왼쪽에 회원 · 할 일, 오른쪽에 OT 진행이 나란히 보임.
- 차수 규칙: 결과가 보류이거나 '이어가요(제안 못 함)'면 다음 차수가 자동으로 열림. 등록이나 실패면 거기서 끝.

### OT 준비하기 (1차 · 2차 이상)
- 1차 'OT 대본':
  - 회원 정보, 담당 트레이너의 가격표(못 읽으면 내 것), 내 라이브러리 별표 자료를 넣어 서버 AI로 만듦.
  - [OT 대본 만들기]를 누르기 전에 무엇을 만드는지 설명이 보임.
  - 목표와 직업이 둘 다 비어 있으면 '목표 한 줄만 적어도…'와 [정보 수정] 링크가 뜸.
  - 만드는 동안 진행 막대와 '1~2분 걸려요. 다른 화면에 다녀와도 괜찮아요' 안내.
  - 서버가 끝까지 만들고 저장하므로, 다른 화면에 갔다 오거나 창을 다시 열어도 4초마다 확인해 결과를 받아 옴(최대 4분, 지나면 '만들지 못했어요').
  - 두 번 눌러도 AI를 두 번 부르지 않음.
  - 재생성할 때 '지금 대본이 1~2분 안 보여요' 확인 창이 뜸.
  - 'N월 N일 시각에 만들었어요'가 보이고, 저장에 실패하면 '이 화면에서만 보여요'.
  - 회원 정보가 바뀌면 '기록이 바뀌었어요 · 다시 만들어 주세요' 배지가 뜸.
  - 옛 형식으로 저장된 대본이면 '이전 형식' 안내가 뜸.
  - 대본 아래에 '1차도 목표는 오늘 PT 등록' 안내가 있음.
- 2차 이상 'OT 대본 · N차':
  - 1차 관찰, 1~(N-1)차 결과 · 제안 여부 · 망설인 이유 · 메모 · 관찰, 가격표 · 별표 자료를 근거로 만듦.
  - 사진 라벨도 함께 보내서 서버가 세일즈북을 이어서 만들게 함.
  - 처음엔 [N차 OT 대본 만들기] 버튼만 있고, 한 번 만들면 다음부터는 저장된 대본이 바로 뜸.
  - 1차 피드백이 없으면 '1차 OT 피드백에 관찰을 먼저 남기면…' 안내만 보임.
  - 앞 차수에서 이미 등록했으면 'N차에 등록 완료 · 준비 필요 없어요'.
  - 1차 관찰이나 이전 차수 결과가 바뀌면 '최신 아님' 배지가 뜸.
  - AI 실패나 저장 실패는 빨간 안내로 보여 주고, 다시 만들 수 있음.
  - 대본 아래 'N차 OT 피드백에 관찰·결과 남기기' 바로가기.
  - 데모 모드에서는 예시(하드코딩 진단 · 조정 팁 · 2차 루틴)를 '예시예요' 라벨과 함께 보여 줌.
  - 내 과거 클로징 케이스 기능: 성공이 5건 이상이면 켜지고, '내 과거 케이스 · 참고' 칸(진짜 걸림돌 · 통했던 접근 · 이번엔 다르게)이 생김. 개발용 `?d3=1`을 붙이면 강제로 켜짐.
- 대본 본문(PrepReport · 1차 · 2차+ · 재등록 공용):
  - 맨 위 '30초 요약 · 이것만 외우기' 세 줄(이 회원 / 오늘 꼭 / 요청). 옛 대본은 기존 항목에서 뽑아 번호로 보여 주고 '다시 만들면 더 짧아져요' 안내.
  - 정보가 거의 없는 회원이면 '○○ 빈칸에 목표를 넣어 말해요' 안내.
  - 수업 순서대로 접힌 칸들. 접혀 있을 때 한 줄 미리보기가 보이고, [모두 펼치기 / 모두 접기]는 '참고' 칸만 빼고 전부 엶.
  - 입장 칸: 1차는 '입장 · 첫 마디', 2차는 '입장 · 지난번 소환'. 대사는 말풍선, '왜'는 '자세히'에 접힘.
  - 1차 운동 칸 'N개':
    - 운동마다 번호 · 이름 · 칸 이름(slot) · '증명' 배지 · 대사.
    - '자세히' 안에 하는 법 · 왜 · 바로 느낌 · 바꿔 쓸 운동 · 내 자료 링크.
    - 맨 아래 '오늘 구성' 한 줄.
  - 2차 운동 칸 '오늘 운동 N개 · 증명 N개':
    - 순서 목록과 내 자료 링크.
    - 증명 동작마다 대사(빨간 강조), '자세히'에 하는 법 · 노릴 반응.
    - '운동별 하는 법 · 포인트 · 반응 약하면' 접기.
  - 옛 대본은 '이름: 하는 법' 한 줄을 둘로 나눠 보여 줌.
  - 내 자료 링크는 http(s)일 때만 새 탭으로 열림.
  - 클로징 칸:
    - 기본은 핵심 4줄(① 되짚기 ② 왜 PT가 필요한지 ③ 추천 플랜과 가격 한 줄 ④ 요청)과 '요청한 뒤엔 먼저 말하지 말고 기다려요.'
    - '전체 순서로 보기 · N줄'에 회원이 말하게 · 쉽게 말하면 · 앞으로 · 약속 · 망설이면이 접혀 있음.
    - '오늘 안 되면 · 숙제' 접기.
    - 옛 대본 형식: ①~⑤에 '이어서 웃으며', 비유는 '자세히'로.
  - 2차 클로징을 세일즈북으로 할 때:
    - 칸 이름이 '클로징 · 세일즈북 넘기며'로 바뀌고 [세일즈북 열기] 버튼이 생김.
    - 핵심 줄마다 해당 장 이름 알약이 붙음.
    - '세일즈북 장 순서대로 전부 보기'에서 장마다 대사와 화면 지시(예: '숫자는 화면이 말하게 2~3초')를 봄.
  - 추천 가격은 대본을 만들 때 저장한 패키지(id)로 지금 가격을 찾음. 옛 대본은 순번으로 찾되 회차가 다르면 가격을 붙이지 않음.
  - 거절 대응 칸: 종류 칩(가격 / 생각해볼게요 / 효과 의심 / 시간 부족 / 다른 곳 비교)을 골라 '이럴 때' · 대사 · '방향'(접힘)을 봄.
  - '참고 · 추천 근거' 칸: 맞는 이유 · 빈도 · 기간 · 그래서 · 대안 패키지와 가격 · '더 좋아지려면'.
- 2차 클로징의 [세일즈북 열기]:
  - 최신 기록을 다시 읽어 세일즈북을 발표 화면으로 바로 엶.
  - 대본을 만든 지 2분이 안 됐으면 '아직 만드는 중' 안내.
  - 2분이 지났는데도 없으면 그 자리에서 만듦(약 20초 안내).
  - 세일즈북은 화면 맨 위 층(body)에 띄움.
- AI 한도:
  - 남은 횟수 한 줄. 베이직은 늘, 프로 · 센터는 적게 남았을 때만 보임.
  - 다 쓰면 만들기 버튼 대신 잠금 카드가 뜸. 베이직은 '프로로 올리기', 프로 · 센터는 '추가 팩 보기'(대표만). 다시 채워지는 날짜도 안내.
  - 만들기가 끝나면 남은 수를 다시 읽음.

### 인바디 분석 (OT n차 칸)
- 입력:
  - 측정일(기본 오늘), 체중 · 골격근량 · 체지방량 · 체지방률 · 기초대사량 · 내장지방, 메모.
  - [측정 저장]: 하나 이상 입력해야 함. 과거 날짜로 넣어도 날짜순으로 다시 정렬됨.
- '최근 측정': 지표마다 지난번 대비 변화(좋음/나쁨 색 · 방향 아이콘)와 작은 추이선.
- '인바디 분석 · 회원에게 보여주기' (AI · OT 칸에서만):
  - [AI 분석] / [다시 분석].
  - 결과 내용: 헤드라인, 지표별 상태와 뜻, 식습관 · 생활습관 · 운동 제안, '그래서 지금부터'. '앱이 분석한 결과예요'라는 말투.
  - 1차 기록에 저장해 두고, 가장 최근 측정일 때만 다시 보여 줌.
  - 한도 남은 수 표시와 잠금 카드.
  - 저장에 실패하면 '이 화면에서만 보여요'.
- '지난 측정' 목록: 지표 한 줄, 메모, 휴지통 → '삭제?' 한 번 더 눌러 삭제.
- 데모 모드에서는 화면에서만 저장 · 삭제됨.

### OT 피드백
- 블록 세 개. 넓은 화면에서는 2~3열로 나란히.
- ① '오늘 어떻게 끝났나요?':
  - 등록했어요 / 다음 OT 이어가요 / 그만하기로 했어요(각각 설명 한 줄).
  - '등록 제안을 했나요?' 했어요 / 아직 못 했어요. 1차에는 'PT 등록이 목표' 힌트.
  - 고른 답에 따라 다음 대본 방향 안내('이번엔 꼭 제안까지' / '클로징 우선').
  - '왜 망설였나요?' 칩 8개.
  - '기억나는 회원의 말' 입력.
  - '다음 OT 날짜'(내일 / 3일 뒤 / 1주 뒤 빠른 선택 + 날짜 고르기, 그날 '오늘 할 일'에 뜸).
- ② '오늘 수업에서 본 것':
  - 준비 대본의 운동이 미리 채워짐(최대 6개).
  - 운동마다 반응 칩(자극 바로 옴 / 본인도 차이 느낌 / 잘 못 느낌 / 불편해함), '★다음에 다시', 빼기.
  - 운동 직접 추가(Enter 가능). 예전 글 기록은 '예전 기록:'으로 보임.
  - 회원 성향 칩 7개.
- ③ '다음 OT 방향':
  - 회원이 진짜 원하는 것 칩 5개와 '왜?' 입력. 처음 말한 목표도 함께 보임.
  - 다음 OT 제안 수위 3개(가볍게 떠보기 / 분명하게 제안 / 오늘 꼭 마무리). 추천값이 미리 골라져 있음.
  - 'AI에게 한마디'.
- [피드백 저장]:
  - 빠진 답이 있으면 안내.
  - 저장 직전에 다시 읽어 서버가 붙인 세일즈북 등을 덮지 않음. 같은 차수 기록이 있으면 그 기록에 저장.
  - 결과가 그대로면 처음 저장 시각을 유지.
- 저장 뒤 '이어가요'를 골랐으면 'N+1차 OT 준비하기' 바로가기가 뜸. 다음 차수가 자동으로 열리고, 배너 · 대시보드도 다시 계산됨.
- 데모 모드에서는 '입력만 가능' 안내. 불러오는 중 표시도 있음.

### 음성일지 (PT 자료남기기 안 '🎙 음성으로 채우기', 접힘)
- 녹음:
  - '수업 요약 녹음 시작' → 파형 애니메이션 · 타이머 · '녹음 중' → '녹음 중지'.
  - 10분이 지나면 자동으로 멈추고 안내가 뜸.
  - 업로드 전 4MB 넘으면 '약 5분 이내로 나눠 녹음' 안내.
  - 마이크 권한을 거부하면 허용 안내가 뜸.
  - 브라우저가 녹음을 지원하지 않거나 AI 키가 없으면(503) 예시 일지가 뜸. 이때 카톡 문구에 '⚠️ 데모 예시' 표시가 붙음.
  - 이번 달 한도를 다 썼으면 잠금 카드와 '직접 적을 수 있어요' 안내. 한도 남은 수 표시.
  - 실패하면 가짜 일지를 채우지 않고 안내만 띄움(소리 없음 / 용량 초과 / 한도 / 네트워크).
- 결과:
  - 'AI가 정제 중…', 기다리는 동안 빈 틀이 보임.
  - 'AI 요약 완료': 1. 진행한 머신과 중량 · 세트(방법 줄 포함), 2. 핵심 피드백, 3. 개인운동 주의사항.
  - [이 내용으로 일지 채우기]: 아래 일지 칸에 카톡 문구(날짜 · N회차 · 마무리 인사는 날짜마다 정해짐)를 넣고 종목 · 세트도 채움.
  - [다시 녹음].
- 센터 장비의 설명 문구(cues)와 회원 장비 목록을 같이 보내고, 같은 회원 · 같은 날 다시 녹음하면 한도에서 새로 세지 않음.

### PT 대시보드
- 화면 안 알약 탭: 대시보드 | 자료남기기 | 케어 | 재등록.
- 회원 카드:
  - 이름, 'PT · N번째 계약' 배지, 나이 · 직업 · 사는 곳, 목표 · 불편 부위, [정보 수정].
- 숫자 칸:
  - 남은 수업(유료 · 서비스, 재등록 때면 빨강).
  - 다음 수업(오늘이면 빨강, 없으면 '스케줄에서 잡아 주세요').
  - 최근 수업(날짜 · N일 전).
  - 이번 달 출석(진행한 수업)과 오운완 N일.
  - 인바디: 목표가 근력 · 벌크 쪽이면 골격근 · 체중, 아니면 체중 · 체지방률. 처음 대비 변화도 표시. 누르면 '더 보기'가 펼쳐지며 그쪽으로 스크롤.
- '이번 계약' 진행 막대(사용 수/전체 수).
- 숫자 목표가 확정돼 있으면 '목표 · …'과 '지금 ○ · 시작보다 ±○ · N개월째' 한 줄. 누르면 케어 탭으로.
- '지금 할 일'(가장 급한 하나, 우선순위 순):
  - 오늘 운동일지 쓰기
  - '내용이 달라요' N건
  - 개인운동 확인(회원이 '아파서 멈췄어요')
  - 개인운동 루틴 만들기(루틴 요청)
  - 회당 단가 넣기(그 자리에서 입력 · 저장)
  - 재등록 준비하기
  - 회원 확인 대기 N개
- 재등록 재료 한 줄: 'N/9 모였어요'와 빠진 핵심 재료. 누르면 재등록 탭으로.
- '더 보기'(접힘):
  - 종목별 무게 추이: 최근 무게, 지난번 대비 변화 · 색, 추이선.
  - 인바디 최근 측정 · 지난 측정(삭제 가능).
  - '회원님 기록일지 · 개인운동 · 유산소 · 비포애프터'(접힘): 운동 스케줄(이번 달 개인운동 · PT 횟수), 유산소(이번 주 합계 분), 비포애프터 갤러리(누르면 크게 보기).
- '지난 수업':
  - 기본은 한 줄씩(회차 · 날짜(KST) · 상태 배지). 배지는 취소됨 / 노쇼 / 확인됨 / 자동 확인 / 변경됨 / 내용이 달라요 / 미확인.
  - 누르면 펼쳐짐: 입력 방식 배지(손입력 · 음성 · 노쇼), 확인 날짜, 종목별 세트(무게×횟수 · 맨몸) · 볼륨 · 총 볼륨, 일지 글, 회원 서명 그림과 시각('자동 확인 뒤').
  - 5개만 보이고 [지난 수업 N회 모두 보기] / [접기].
  - '⋯'을 누르면 [수정] · [삭제].
  - 수정: 일지 글만 그 자리에서 고침. 이미 확인된 수업이면 경고가 뜸.
  - 삭제: 실제로 지우지 않고 '취소됨' 처리. 확인 창(출석 · 차감에서 빠짐, 언제든 무르기 가능, 이미 확인된 수업이면 경고). 취소된 일지에는 [무르기]가 늘 보임.
  - '내용이 달라요'는 접혀 있어도 보임(회원 메모와 '고치면 다시 확인받아요 / 받지 않은 수업이면 삭제' 안내).
  - 회원 확인 뒤 내용이 바뀌었는지 내용 대조로 찾아 '변경됨' 표시. 자동 확인된 수업은 수정 시각으로 판정.
- [수업 확인서] 버튼(지난 수업 머리) → 아래 '수업 확인서' 참고.
- 넓은 화면에서는 왼쪽에 대시보드와 더 보기, 오른쪽에 지난 수업(고정되어 따로 스크롤).

### PT 자료남기기
- 순서: 수업권 · 재등록 → 오늘 운동일지 → 인바디 기록 → 비포애프터 사진 → 환불(접힘).
- '수업권 · 재등록' 카드:
  - 남은 수업(유료 · 서비스), '재등록 타이밍' 배지, '다음 계약 N회 대기'.
  - 계약이 없으면 안내가 뜸.
  - [계약 등록] / [새 계약 등록] 창: 세션 수 · 단가 · 총액 · 서비스. 앞 계약이 있으면 재등록으로 저장되고 '남은 수업 다 쓰면 이어져요'.
- '오늘 운동일지 · 수업 확인서':
  - 음성으로 채우기(접힘), 수업 내용 입력 칸.
  - '종목 · 세트 기록'(접힘, 세트가 있으면 펼쳐짐):
    - 종목 이름은 센터 머신 목록에서 검색해 고를 수 있음.
    - 세트마다 무게 kg × 횟수, 세트 · 종목 추가와 삭제.
  - 계약이 없으면 '차감도 급여도 안 들어가요' 경고.
  - [저장 + 차감] / [저장(차감 없음)]:
    - 글을 카톡용으로 자동 복사(복사한 시각도 기록).
    - 회원 폰에 운동일지 알림.
    - 오늘 그 회원의 예약 중 지금 시각에 가장 가까운 것을 '완료'로 연결.
    - 결과 안내('수업 1회 차감했어요 · 카톡 문구를 복사했어요' 등).
  - [노쇼 차감]: 두 번 눌러야 저장됨(4초 안에, '한 번 더 누르면 노쇼 차감').
- 인바디 기록 입력(OT와 같음).
- 비포애프터 사진:
  - 분류(비포 · 진행 · 애프터)와 날짜를 고르고 [사진 올리기]. 압축 뒤 회원 폴더로 올림.
  - 트레이너가 올린 사진만 삭제할 수 있음.
- 데모 모드에서는 화면에서만 저장 · 차감됨(안내에 '(데모)').

### PT 케어 (목표 · 로드맵 · 루틴 · 식단 · 회원 페이지)
- 순서: 현재 방향 · 목표 → 식단 → 목표 로드맵 → 개인운동 루틴 → 회원 전용 페이지.
- '현재 방향 · 목표':
  - [설정/수정]으로 글을 저장.
  - 글을 읽어 '앱이 읽은 목표'를 보여 줌 → [맞아요]를 눌러야 숫자 목표가 됨. 시작 값은 이번 계약을 시작할 때의 기록.
  - [고치기]: 지표 칩(체중 · 골격근량 · 체지방량 · 체지방률 · 운동 무게), 종목 선택, 늘리기/줄이기, 얼마나, 기간(1 · 2 · 3 · 4 · 6 · 12개월). 결과를 미리 보고 저장.
  - 글에 숫자가 없으면 '숫자로 정하기' 링크. 기록이 없으면 '인바디를 한 번 재면…' 안내.
  - 숫자 목표 카드: 목표, '지금 · 시작보다 · N개월째', [회원에게 보이기/안 보이기], [고치기], [지우기].
  - 글이 바뀌었으면 '앱이 읽은 목표는 …예요 · 이걸로 바꾸기'.
- '다음 목표'(재등록 타이밍이거나 목표를 이뤘을 때 · 지금 목표가 있을 때만):
  - 지난 속도로 계산한 추천 글이 미리 채워짐. 고쳐 쓸 수 있고, 숫자로 읽힌 결과가 미리 보임.
  - [이걸로 바꾸기]: 바로 지금 목표가 되고, 이번 목표의 결과와 다음 목표가 계약 기록에 남음.
- 식단 → 아래 '식단(트레이너)' 참고.
- 목표 로드맵:
  - 없으면 안내와 [AI 초안 만들기](한도 · 잠금 카드) / [직접 만들기].
  - 편집:
    - 제목(40자).
    - 단계 최대 6개. 이름 30자 · 설명 80자.
    - 동그라미를 눌러 '지금 단계'로 지정.
    - 위/아래 이동 · 빼기 · 단계 추가.
    - 저장할 때 빈 단계는 빼고 번호를 다시 매김.
  - 보기: 지난 단계 ✓, 지금 단계 '지금'과 설명, '회원에게 보이는 중/안 보임'.
  - [회원에게 보이기/안 보이기], [다음 단계로 ▶](자동으로 넘어가지 않음), [고치기].
  - 표가 아직 없으면(SQL 실행 전) 카드가 숨겨짐.
- 개인운동 루틴:
  - 없으면 회원의 루틴 요청 표시, 구성 고르기(전신 / 상체·하체 / 밀기·당기기·하체 / 부위별, 마지막 선택을 이 기기에 기억), [루틴 만들기].
  - PT 기록이 2번 이상인 종목이 없으면 안내가 뜸.
  - 편집:
    - 회원에게 한마디(200자, 글자 수 표시).
    - 날(덩어리)별 탭.
    - 종목마다 부위 옮기기(그 부위가 들어간 덩어리로 이동), 위/아래 · 빼기.
    - 무게 · 횟수 · 세트를 +/−로 조정.
    - 혼자 상한 · 한 칸 · PT 기록 · 워밍업 표시.
    - 경고: 'PT보다 무거워요', '무게를 한 번 더 확인해 주세요'.
    - '불편 부위 관련' 배지, [무게 고정], 한 줄 설명.
  - 종목 추가: PT에서 한 종목(위험 종목은 ⚠ 표시), 등록한 장비, 직접 입력.
  - [최신 PT 기록으로 다시 계산](확인 창), [확정](확정해도 회원에게는 아직 안 보임).
  - 보기 화면 경고 · 안내:
    - 회원 루틴 요청이 있음.
    - PT가 4주 넘게 끊겼다 다시 시작해 회원 화면에서 숨김.
    - 회원이 '아파서 멈췄어요'를 눌러 그 종목 진도가 멈춤.
    - PT에서 더 무겁게 해서 [최신 PT 기록으로 다시 맞추기]가 필요함.
    - 회원이 혼자 상한보다 무겁게 했음.
    - 루틴 밖 운동을 2번 이상 함.
    - 같은 종목을 3번 연속 '자리 없음'으로 못 함.
  - 보기 화면 내용:
    - 덩어리별 '다음 ○kg × ○회 × ○세트'(혼자 상한 · 아파서 멈춤 · 고정 자물쇠 표시).
    - '지난 PT 이후 개인운동 N회'(최근 6회 · 못 함 이유 · 세트별 기록).
  - 불편 부위가 있는 회원은 '확인했어요'를 체크해야 [회원에게 보이기]가 켜짐. 누가 확정 · 공개했는지 기록됨.
  - 회원이 루틴을 요청한 상태에서 루틴을 공개하면 요청이 처리 완료로 바뀜.
  - '회원에게 하는 설명'(접힘): 설명 대사와 [복사](카톡용).
- 회원 전용 페이지 카드: 링크 만들기 · 복사 · 끄기(테두리 없는 간단한 모양).

### PT 재등록
- 계약이 없으면 '아직 계약이 없어요'와 자료남기기 바로가기.
- 두 번째 계약부터 회차 알약(첫 재등록 · N번째 재등록). 지난 회차의 대본 · 세일즈북 · 결과를 봄. 결과는 고칠 수 있고, 새로 만드는 것은 지금 회차만.
- 회차 한 줄: '이번 계약 N회 + 서비스 중 N회 진행 · 남은 N회', '재등록 타이밍' 배지. 지난 회차는 시작일.
- 미리 재등록한 경우: 다음 계약이 있는데 결과가 없으면 '재등록했어요를 저장해야 재등록률에 들어가요'.
- 재등록 재료(9칸):
  - 회원 목적별로 핵심 재료가 ★로 표시되고, 빠진 핵심 하나가 맨 위에 크게 뜸('케어 탭으로 가기' 또는 [했어요]).
  - '재료 9개 모두 보기'(접힘): 인바디 변화 · 무게 변화 · 꾸준함 · 사진 · 회원의 말 · 개인운동 · 숫자 목표 · 다음 단계 맛보기 · 다음 목표. 모인 것은 실제 문장으로, 빠진 것은 채우는 방법으로 보임.
  - '다음 단계 맛보기' [했어요]는 계약 기록에 저장됨.
- 회원 만족도:
  - 칩 4개(아주 만족 / 만족 / 보통 / 아쉬워함)는 누르면 바로 저장.
  - 회원이 한 말은 입력 칸을 벗어날 때 저장. 저장 중에 또 바뀌면 이어서 저장.
  - '함께 넘기는 변화' 미리보기.
- '재등록 상담 대본':
  - 넘기는 재료: 변화 · 출석 · 만족도 · 로드맵 · 숫자 목표 · 다음 목표 · 두 번째 이상이면 이번 계약 기간 숫자와 지난번 약속.
  - [재등록 대본 만들기]: 한도 · 기다림 안내, 돌아왔을 때 이어 받기.
  - 본문은 OT와 같은 문서 모양:
    - '오늘 수업 흐름': 꺼낼 타이밍, '아직 남은 부분 알려 주기' · '목표 한 단계 올리기'를 지시 + 말풍선으로 나눔, 내 자료 링크.
    - 옛 대본만 '그동안의 변화 → 앞으로' 칸이 있음.
    - 클로징('왜 지금 이어가야 하나') · 혜택(덤).
    - 거절 대응은 기록된 망설인 이유 칸이 먼저 열림.
  - 클로징의 [세일즈북 열기]: 아직 없으면 한 번 더 읽어 보고, 없으면 안내.
- '재등록 세일즈북':
  - 대본을 만든 뒤 서버가 이어서 만들고, 화면은 8초마다 최대 2분 다시 확인함('이어서 만들고 있어요'). 대본을 만든 지 3분 안에 돌아오면 다시 기다림.
  - [회원에게 보여주기], [세일즈북 만들기 / 다시 만들기].
  - 변화 기록이 적으면 안내가 뜸.
- '오늘 어떻게 끝났나요?':
  - 재등록했어요 / 생각해 본대요 / 이번엔 안 하기로 했어요 / 아직 이야기 안 했어요.
  - 망설인 이유 칩 7개.
  - 생각해 본대요를 고르면 '재접근 예정일'(2주 · 1개월 · 3개월 빠른 선택 + 날짜 고르기, '오늘 재접근'에 뜸).
  - [저장]은 바뀐 게 있을 때만 켜짐.
  - '재등록했어요'면 '새 계약은 자료남기기에서' 링크.
- 등록 이력(계약 3개 이하면 펼쳐져 있음):
  - 순번 · 신규/재등록/인계 · 상태(진행 중 · 대기 · 끝남 · 인계로 닫힘 · 환불) · 시작일.
  - 회차 · 서비스 · 회당 단가 · 금액 · 환불, 진행 막대.
  - 끝났을 때 결과와 회원 한마디. 합계 금액.
- 세일즈북 탭에서 `?sb=1`로 들어오면 세일즈북이 준비되는 대로 발표 모드로 바로 열림.

### 수업 확인서 · 운동일지 확인 상태
- 일지 배지: 확인됨 / 자동 확인 / 변경됨 / 내용이 달라요 / 미확인 / 노쇼 / 취소됨. 확인 날짜, 서명 그림과 시각(자동 확인 뒤 여부).
- 월별 수업 확인서(전체 화면):
  - ‹ › 로 달을 옮김.
  - 회원 · 담당 트레이너 · 수업 횟수(노쇼 따로) · 서명 횟수.
  - 표: 날짜 · 시각(KST) / 내용 요약(종목 외 N · 세트) / 확인 상태와 시각 / 서명 그림.
  - 자동 확인인데 서명이 없으면 '자동 확인(서명 없음)'으로 그대로 적음.
  - 머리에 센터 이름 또는 상호(개인 계정).
  - [인쇄 · PDF 저장]: A4로 이 장만 출력. 출력일이 적힘.
- 확인한 뒤 내용을 고치면 회원 화면에 '변경됨'으로 보인다는 경고.

### 식단 (트레이너)
- 식단 카드(케어 탭 · 표가 없으면 숨김):
  - 꺼져 있을 때: 설명과 [식단 관리 켜기]. 건강정보 동의가 없으면 동의 방법 안내.
  - 켜져 있을 때 머리: '켜짐' 배지, 목적 · 기간 · 목표 kg.
- 숫자 칸: 운동 없는 날 / 운동한 날 kcal, 탄 · 단 · 지 g, N주차 / 전체 주 · 체중 변화. 질환이 있는 회원은 '기록 관리만'.
- 식단 요청: 오늘 남은 끼니 / 이번 주, 상황, 몇 번째, 시각, 'N분 뒤 AI' / '곧 AI' / '직접 답하기'.
- 최근 식단(7일):
  - 날짜 · N끼 · '회원이 끝 누름' / '올리는 중'.
  - 상태: 보냈어요 / AI가 보냈어요 / 피드백 보내 주세요 / 오전 6시 AI / 곧 AI.
  - 최근에 답한 요청 2개(넘김 / AI / 보냄).
- 예시 식단(접힘): 회원에게 보이는 예시, [만들기 / 다시 만들기].
- [숫자 고치기], [끄기](확인 창).
- '오늘' 탭 카드에서 누르고 들어오면 그 요청이나 그 날 창이 바로 열림(60초 안).
- 켜기 / 숫자 고치기 창:
  - 목적(다이어트 / 벌크업 / 바디프로필 / 대회 준비 / 건강관리, 회원 목표에서 미리 골라 둠).
  - 기간(1 · 2 · 3 · 4 · 6개월), 목표 체중(늘리기/줄이기). 대회 준비는 kcal · 탄단지를 직접 입력.
  - 목표량 미리보기(기초대사량 · 인바디 날짜 기준).
  - 빠듯하면 'N개월이면 안전해요'와 [N개월로 바꾸기].
  - 질환이 적힌 회원은 숫자 없이 기록 관리만, 의사 · 영양사 안내.
  - 인바디가 없으면 안내가 뜸.
  - 처음 켜면 예시 식단을 자동으로 만듦.
  - DB가 막을 때 안내: 건강정보 동의 필요 / PT 회원만.
- 하루 피드백 창:
  - 회원이 '오늘 식단 끝'을 눌렀는지 안내(누름 / 아직 / 지난 날).
  - 끼니 사진과 글, 먹은 시각, '피드백 뒤' 표시, 끼니 분석(음식 · kcal).
  - [AI 초안으로 하루 피드백 쓰기](약 20초): 사진 기준 kcal · 목표 · 단백질을 보여 주고 잘한 점 · 다음엔 하나만 · 먹은 시간을 고친 뒤 [보내기].
  - [하루 피드백 직접 쓰기].
  - 그냥 두면 AI가 보낸다는 안내, 한도 남은 수.
  - 보낸 피드백 보기('AI가 트레이너 이름으로 보냈어요'), '한마디 덧붙이기'.
  - 보내거나 덧붙이면 회원 폰에 알림이 감.
- 식단 요청 창:
  - 요청 내용 · 회원 메모 · N번째.
  - [AI 초안으로 요청에 답하기]: 소개 · 끼니별 · 마무리를 고친 뒤 보내기.
  - [요청에 직접 답하기]: 자유 글.
  - 3번째 요청에만 [넘기기(회원과 직접 이야기할게요)].
  - 'N분 안에 안 보내면 AI가…' 안내. 이미 답한 요청은 내용 보기. 회원 폰 알림.

- 비포·애프터:
  - 사진이 2장 이상인 내 회원 목록(장 수 · 기간) → 사진 2장 고르기('회원' 업로드 표시).
  - 목적 칩(회원 목표로 추정해 미리 고름), 익명 이름 자동('30대 여성 · 12주', 고칠 수 있음), 메모.

  - 종류별 화면: 사진 2장(누르면 크게), 인바디 지표 줄, 운동 큰 숫자와 추이선, 캡처.

- 숫자는 기록에서 그대로 가져온 값이라 손으로 고칠 수 없음. 화면에는 익명 이름만 보임.

  - 사진 기록(처음 · 지금 사진이 모두 있을 때만).
  - 지금 어디까지 · 앞으로(STEP 4개 · 지난 단계 ✓ · '지금 여기').
  - 지금 멈추면 · 이어가면.

## 3. 대표 화면

### 대표 화면 틀 (메뉴 · 전환 · 빈 상태 안내)
- `/admin`은 대표만 열 수 있어요. 대표가 아니면 "대표만 볼 수 있어요"와 [트레이너 화면으로] 버튼이 떠요.
- 개인 계정(solo)이 `/admin`에 들어오면 트레이너 홈(`/`)으로 바로 돌려보내요.
- 키가 없는 데모 모드에서는 대표 화면이 그냥 열리고 "데모 모드예요…" 안내 줄이 떠요.
- 불러오는 동안 "불러오는 중…"이 보여요. 기록을 못 읽으면 위쪽 안내 줄에 "새로고침해 주세요"가 떠요.
- 폰 메뉴는 위쪽 가로 탭 7묶음이에요: 홈 · 보고서 · 매출 · 정산 · 트레이너 · 등록·이탈 · 운영.
- 태블릿·PC(768px 이상)에서는 같은 7묶음이 왼쪽 세로 메뉴로 가요. 1280px 이상이면 메뉴에 센터명과 '대표 · 총괄 경영'까지 넓게 보여요.
- 하위 화면이 둘인 묶음은 위쪽 알약 칩으로 골라요.
  - 보고서: 아침 보고서 | 월간 결산
  - 정산: 정산 보기 | 장부 적기
  - 트레이너: 성과·리더보드 | 급여 설정
  - 운영: 스케줄 | 센터 운영
- 폰 머리에는 브랜드 마크(대표 색 침), 센터명(`account.name`, 없으면 '내 센터'), '대표 · 총괄 경영'이 보여요.
- '트레이너 화면' 버튼(폰 머리 · 왼쪽 메뉴 맨 아래)을 누르면 트레이너 앱(`/`)으로 넘어가요.
- 주소의 `?tab=monthly` 같은 값으로 그 탭을 바로 열어요. 폰 알림을 눌렀을 때 쓰여요.
- 옛 탭 이름(funnel · retention)은 등록·이탈로 자동으로 옮겨 가요.
- 회원이 0명이면 모든 탭 위에 '센터를 시작하는 중' 안내가 떠요. 탭마다 다른 한 줄과 지금 트레이너 수 · 회원 수가 같이 보여요.

### 폰 홈 (OwnerHub · 1024px 미만)
- 맨 위에 '처음 시작하기' 체크리스트가 떠요. 가입 30일 안에만 보이고, 끝난 줄은 기록을 읽어 자동으로 지워져요.
  - 대표 첫날 줄: 트레이너 초대 · 센터 장비 · 급여 규칙 · 센터 QR · 회원 옮겨 오기와 배정
  - 대표 첫 주 줄: 폰 알림 · 정산 시작일 · 첫 이벤트 · 내 소개
  - '나중에 하기'를 누르면 한 줄로 접혀요(이 기기에 기억). 다 마치면 축하 한 줄이 하루 동안 떠요.
  - 체크리스트의 '센터 장비'(/settings/gear), '회원 옮겨 오기와 배정'(/members/import), '첫 이벤트'(/settings/reward)는 트레이너 앱 화면으로 나가요. 대표 화면 탭으로 가는 줄은 누르면 그 탭으로 바로 바뀌어요.
- 센터 QR로 들어온 신청이 있으면 'OT 신청 N건이 배정을 기다려요' 카드가 떠요. 가장 오래 기다린 시간이 같이 보이고, 누르면 등록·이탈 탭으로 가요.
- 매월 1~10일에 아직 안 연 지난달 결산이 있으면 'N월 결산이 준비됐어요' 카드가 떠요. 누르면 월간 결산으로 가요.
- 날짜 · 요일과 '○○ 대표님' 인사가 보여요.
- '오늘' 카드에는 숫자 4칸이 있어요.
  - 오늘 수업(완료 · 남음)
  - 오늘 신규 OT
  - 이달 매출(목표 대비 %, 목표가 없으면 신규 · 재등록 건수)
  - 클로징률 · 재등록률(누적)

### 매출 탭
- 이달 매출 현황: 큰 금액이 보이고, 목표가 있으면 목표 · 현재 · 달성률 · 막대가 같이 떠요. 100%를 넘으면 '목표 달성' 배지가 붙어요.
- 트레이너별 목표 줄: 현재/목표/% 또는 '목표 미설정'이 보여요.
  - 목표도 매출도 없는 대표는 목록에서 빠져요.
  - 목표를 안 세운 트레이너가 있으면 "센터 목표가 작게 잡혀 있어요"가 떠요.
- 목표가 없으면 "트레이너가 '내 실적'에서 정하면 합산돼요"가 떠요. 대표가 여기서 목표를 정하는 칸은 없어요.
- 다음 달 예상 매출(추정 배지)
  - 신규 유입: OT 진행 인원 × 클로징률 × 평균 금액으로 계산해요.
  - 재등록: 만료 임박 인원 × 재등록률 × 평균 금액으로 계산해요.
  - 이력이 부족하면 "더 쌓이면 보여 드려요"가 떠요.
- 이달 매출 구성: 신규 vs 재등록 막대와 금액 · 건수 · 비중이 보여요. 환불이 있으면 '환불 −○ · 순매출'이 같이 떠요.

  - 알게 된 경로 집계가 보여요.
  - 트레이너별로 받은 신청 · 첫 OT 예약 · 등록 수가 보여요.
  - 신청마다 출처(센터 QR · 트레이너 링크)와 단계(신청 → 배정 → 첫 OT 예약 → 1차 OT → 등록, 또는 '넘김')가 보여요.
- 신규 OT → PT 등록: 큰 클로징률, OT 회원 N명 중 M명 등록이 보여요. 4단계 막대에 단계마다 −N명 이탈이 표시되고, 1차 · 2차 등록률이 같이 나와요(누적 스냅샷 안내).
- '달마다 클로징률 · 나아지고 있나': 6개월 유입 코호트 막대예요. 회색은 유입, 파랑은 등록이고 이번 달은 흐리게 보여요.
- 'PT 회원 · 재등록과 이탈' 3칸: 재등록률 · 만료 임박(모두 재등록하면 금액) · 이탈 위험(남은 수업).
- 명단 4줄은 누르면 제자리에서 펼쳐요.
  - 1차 OT 대기
  - 이번 주 챙길 등록(2차 후 미결정 · 재상담 날짜)
  - 만료 임박(잔여 유료 · 마지막 방문)
  - 이탈 위험(N일째 무수업 · 잔여)
- 명단은 20명까지 보이고, 넘으면 '외 N명'이 떠요.
- 맨 아래 '트레이너별 클로징률·재등록률 보기' 링크를 누르면 트레이너 탭으로 가요.

### 스케줄 (운영 묶음 안)
- 요약 4타일: 최근 90일 예약 · 완료율(완료/취소) · 노쇼율(운동일지 기준) · 미처리 예약.
- '이번 달 진행 수업' 트레이너별 표: OT · PT · 합계와 센터 합계가 보여요.
- 요일 × 시간(6~24시) 예약 밀도 히트맵이에요. 가장 붐비는 칸 라벨이 붙고, 칸에 올리면 건수가 떠요. '가동률이 아니라 밀도'라는 안내가 같이 있어요.
- 트레이너별 표: 예약 · 완료 · 취소 · 미처리 · 완료율 · 노쇼율, 색으로 등급을 보여요.
- '미처리 예약' 목록: 시간이 지났는데 완료 · 취소를 안 한 예약이에요. 회원 · 트레이너 · 시각이 보이고 20건까지 나와요.
- 스케줄 탭은 보기만 해요. 예약을 고치는 기능은 없어요(트레이너 앱 스케줄에서 해요).

### 급여 (트레이너 묶음 '급여 설정')
- 맨 위 안내 버튼: "이달 급여 계산·확정은 트레이너 탭에서" → 트레이너 탭으로 가요.
- 적용 대상은 '계정 기본'이나 트레이너별 전용 정책 중에서 골라요. 전용 정책이 있는 트레이너엔 ● 표시가 붙어요.
- 지급 방식은 '밴드 자동' 또는 '수동(월별 입력)'이에요. 수동이면 대표가 확정 화면에서 최종액을 직접 넣어요.
- 밴드 기준은 매출 기준 또는 수업수 기준이에요.
- 구간마다 이 값 이상 · 지급 유형(판매가 % · 회당 정액 · 고정액) · 지급 값 · 인센티브(없음 · % · 정액)를 정해요. 구간은 추가 · 삭제할 수 있어요.
- 예상 급여 미리보기: 예시 매출 · 수업수 · 수업료합을 넣으면 기본 + 인센 · 예상 급여가 바로 계산돼요.
- [급여 방식 저장]이 있어요. 트레이너 전용 정책은 [이 트레이너 정책 삭제(계정 기본 따름)]로 지워요.

### 운영 탭 (센터 운영)
- **회원 등록·배정**
  - [새 회원 등록·배정]을 누르면 회원 등록 창이 떠요. 담당 트레이너를 고르고, 등록 유형(신규 OT · 인계받은 PT · 외부 PT)과 남은 세션 · 회당단가를 넣어요.
  - 트레이너가 없으면 "먼저 트레이너를 초대해 주세요"가 떠요.
  - 저장하면 회원 목록을 다시 읽어요.
- **회원 재배정(트레이너 인계)**
  - 트레이너가 2명 미만이면 안내만 떠요.
  - 창에서 PT 회원을 이름 · 직업으로 검색해 고르면 현 담당과 이월할 잔여 · 회당단가가 미리 채워져요.
  - 새 담당을 고르고 이월 세션 · 단가를 고칠 수 있어요. '미완료 예약도 새 담당에게' 체크도 있어요.
  - [인계하기]를 누르면 새 담당 이월계약(매출 0)을 만들고, 옛 계약을 닫고, 담당과 예약을 옮겨요.
  - 실패하면 몇 번째 단계에서 멈췄는지 안내가 떠요.
- **트레이너 추가**
  - 이메일 · 이름을 넣고 [추가]하면 계정이 생겨요. 임시 비밀번호는 그 화면에서만 한 번 보여요.
  - 좌석 '사용/전체'가 표시돼요. 자리가 다 차면 추가가 막히고 "구독 관리에서 1명 더할 수 있어요"가 떠요.
- **트레이너 아이디 관리**
  - 트레이너마다 [아이디 끄기](확인 창)와 [다시 켜기]가 있어요.
  - 꺼진 아이디엔 '꺼짐'과 'M월 D일까지 보관'이 붙어요. 30일이 지나면 '곧 정리돼요 · 다시 켤 수 없어요'로 바뀌고 다시 켜기 버튼이 사라져요.
  - 정리가 끝난 아이디는 목록에서 빠져요.
- **꺼진 · 없는 트레이너의 담당 회원**
  - 'N명이 남아 있어요'와 이름 일부가 보여요.
  - 받을 트레이너를 고르고 [한꺼번에 넘기기](확인 창)를 누르면 진행이 'i / N'으로 보여요.
  - 넘기지 못한 회원은 이름과 함께 "회원 재배정으로 한 명씩"이 안내돼요.
  - 끌 사람도 넘길 회원도 없으면 이 카드는 안 보여요.
- **공지(대표 → 트레이너)**
  - 제목 · 본문을 쓰고 대상은 전체 또는 특정 트레이너(칩)로 정해요.
  - '필수확인'(트레이너가 앱을 열 때 확인을 요구)과 '고정(핀)'을 켤 수 있어요.
  - [게시] 또는 [수정 저장] · [취소]가 있어요.
- **게시한 공지 목록**
  - 핀이 먼저, 그다음 최신 순이에요. 필수확인/일반 배지, 대상 칩, 'n/m 읽음'이 보여요.
  - 핀 켜기/끄기 · 수정 · 삭제('삭제?' 두 번 확인)를 할 수 있어요.
- **회원 이벤트 · 이벤트 목록**: 트레이너 설정 '이벤트' 탭과 같은 화면이에요(1장 '이벤트 탭' 참고). 대표는 대상을 '센터 전체 회원' 또는 '○○ 트레이너 회원'으로 골라요.

### 기타 (트레이너 앱과 공유 · 연결)
- 트레이너 앱 머리와 왼쪽 메뉴에 '대표 화면' 버튼이 있어요. 센터 대표에게만 보이고, 누르면 `/admin`으로 가요.
- 대표도 트레이너 앱을 그대로 써요(본인 회원 · 수업).
  - 회원 목록에 '내 회원 | 전체' 칩이 생겨요.
  - 스케줄에 트레이너 필터 · 색 범례 · 트레이너 이름이 붙어요.
  - 센터 장비 등록 · 삭제는 대표만 할 수 있어요.
  - '여러 명 한꺼번에 등록'에서 담당 배정까지 해요.
- 설정 › 내 정보 '구독 관리'는 대표(개인 계정은 주인)만 봐요. 내용은 1장 '내 정보 탭'의 구독 관리와 같아요.
- AI 한도를 다 쓰면 대표에게만 '추가 팩 사기' 안내가 떠요(트레이너에겐 "대표에게 부탁해 주세요").
- 설정 '알림'에 대표만 보이는 줄이 있어요: 'OT 신청 배정 대기', '아침 보고서'.
- 대표 폰으로 가는 알림: 배정 대기 · 아침 보고서 · 월간 결산(`/admin?tab=monthly`) · 계정 알림(`/admin?tab=ops`).
- 급여 확정, 대표 피드백, OT 배정, 이벤트 알림은 대표 화면에서 저장하는 순간 트레이너 · 회원 폰으로 가요.

## 4. 회원 전용 페이지

### 회원 페이지 로그인·관문
- 트레이너가 보낸 개인 링크(`/m/{토큰}`)로 열고, 휴대폰 뒤 4자리를 넣어 들어간다(숫자 4자리만 입력, Enter로도 확인).
- 4자리가 틀리거나 링크가 맞지 않으면 "링크가 맞지 않거나 휴대폰 번호가 달라요"가 뜬다.
- 같은 링크로 여러 번 시도하면 "시도가 많아요. 잠시 뒤 다시 시도해 주세요"가 뜬다(10분에 6번).
- 계속 틀리면 "여러 번 틀려서 잠시 막아 뒀어요. 10분 뒤 다시"가 뜬다(회원당 10분 8번, 같은 IP 30번).
- 환불·삭제된 회원은 "이 페이지는 닫혔어요"로 로그인이 막힌다.
- PT가 끝나고 6개월이 지난 회원은 "이 페이지는 닫혔어요. 다시 시작하려면 트레이너에게"로 막힌다.
- 센터 구독이 끝났거나 프리미엄이 아니면 "회원 전용 페이지 이용이 잠시 중단됐어요"가 뜬다(기간 끝 뒤 30일은 볼 수만 있음).
- 한 번 로그인하면 이 기기에서는 다음에 바로 홈으로 들어온다(트레이너 로그인과 따로 저장).
- 공용 기기에서 다른 회원의 링크를 열면, 앞 회원은 이 기기에서만 로그아웃되고 새 로그인 화면이 뜬다.
- 정보를 못 불러오면 "정보를 불러오지 못했어요" 카드와 [다시 로그인] 버튼이 나온다.
- 키가 없는 데모 모드에서는 "데모 모드라 로그인할 수 없어요"가 뜬다.
- 첫 화면 동의(ConsentGate): 운동일지 확인 방법(필수), 개인정보 수집·이용(필수), 건강정보(선택)를 항목별 표로 읽고 체크한다.
- 필수 두 개를 체크해야 [동의하고 시작하기]가 켜지고, 그 전에는 기록이 하나도 보이지 않는다.
- 동의서 문구가 바뀌면 "바뀐 내용이 있어요"(서명·24시간 자동 확인 안내)로 다시 묻는다. 이미 동의한 건강정보는 다시 묻지 않는다.
- 동의 화면 안내 문장에 운영 주체가 나온다(센터명, 개인 트레이너면 "상호 · 이름 트레이너").
- 동의 화면에 개인정보처리방침 새 창 링크와 [나가기](로그아웃)가 있다.
- 동의 기록을 못 읽으면 동의 화면을 건너뛰어 회원을 잠그지 않는다. 이때 건강정보는 '동의 안 함'으로 본다.
- 홈 화면에 추가하면 이 회원 페이지로 바로 열리는 전용 앱 정보가 붙는다(이름 "오직 트레이너 회원", 짧은 이름 "내 PT", 세로 화면).
- 회원 페이지는 검색에 나오지 않게 막혀 있다.

### 회원 홈
- 머리: 로고 + "○○ 회원님 공간", 목표·시점·담당 트레이너 알약이 보인다.
- 탭 4개(홈 · 운동일지 · 변화 · 기록하기)가 화면 위에 붙어 있어 스크롤 중에도 바꿀 수 있다. 바꿔도 쓰던 글과 펼친 것이 남는다.
- 운동일지 탭에 확인 안 한 일지 수가 빨간 숫자로 붙는다.
- 볼 수만 있는 상태면 띠 안내가 3가지로 갈린다: 센터 이용 기간 끝, 남은 수업 0회(재등록하면 다시 열림), PT 종료("○년 ○월 ○일까지 볼 수 있어요").
- 볼 수만 있는 상태에서는 '기록하기' 탭과 삭제 버튼이 사라진다.
- 트레이너가 센터로 옮길 때 '기록을 함께 옮길까요?' 창이 뜬다. [함께 옮겨 주세요] / [옮기지 않을래요], 답 기한 안내가 있다.
- 그 창을 닫아도 "기록을 ○○로 함께 옮길지 골라 주세요 · ○월 ○일까지" 띠로 다시 열 수 있다.
- 열린 이벤트 띠가 최대 3개 보인다(제목·상품, 상태: 참여하기 / ○일부터 신청 / 정원 마감 / 참여 중 n/m회 / 달성! / 받았어요).
- 폰 알림이 꺼져 있으면 "운동일지 · 예약 · 이벤트 알림 받기 [켜기]" 한 줄이 나온다.
- 식단 관리 중인 회원에게는 '어제 식단 피드백' 카드와 "요청한 식단이 왔어요 · n개 →" 버튼이 보인다.
- '내 PT' 카드: 남은 수업(크게) / 전체, 진행 막대, "n회 진행 · 유료 · 서비스 · 다음 계약 n회 대기".
- 진행 중인 계약이 없으면 "진행 중인 PT 계약이 없어요."가 나온다.
- '내 PT' 안에 '수업 일정'(예약 카드)이 들어 있다. 지난 회원에게는 "다음 수업" 한 줄만 보인다.
- 트레이너가 공개한 숫자 목표가 '이번 목표'로 보인다(목표 문장 + 지금 값·시작보다 변화).
- 트레이너가 공개한 '나의 목표 로드맵'은 접혀서 "지금 n단계"로 보인다. 펼치면 단계(완료 체크·지금 표시), 누르면 한 줄 설명이 나온다.
- 오운완 카드: 오늘 했으면 "오늘 오운완 완료!"와 "n일 연속으로…", 아니면 "오늘은 아직이에요"와 [기록 남기러 가기].
- 오운완 숫자(이번 달·누적·연속)는 서버 집계라 기록이 많아져도 줄지 않는다.
- 오운완 배지 5개(첫 오운완 · 불꽃 7일 · 꾸준 10회 · 든든 30회 · 골드 60회): 받은 것은 빨강, 못 받은 것은 흐리게.

### 회원 기록 남기기 탭
- 맨 위 식단 카드(식단 관리 회원만), 그 아래 개인운동 루틴 카드가 있다.
- 루틴이 없으면 [루틴 요청하기] → "요청했어요. 트레이너님이 만들면 여기에 보여요"와 [요청 취소]. 트레이너 폰에 알림이 간다.
- 트레이너가 다시 확인 중이면 "트레이너님이 루틴을 다시 확인하고 있어요"만 나오고 숫자는 안 나온다.
- 오늘 할 부위가 자동으로 정해진다(가장 오래 안 한 부위). "n일 전에 했어요", 모두 최근이면 "오늘은 가볍게"가 붙는다.
- [다른 부위 하기]로 부위 칩(며칠 전·쉬어요 표시)을 골라 바꿀 수 있다.
- 트레이너 한마디 말풍선이 있다(트레이너가 적었을 때만).
- 종목마다 워밍업 안내, 트레이너 메모, '트레이너가 고정한 무게'(자물쇠), '최근 PT에서 한 부위 · 빼거나 가볍게' 표시가 붙는다.
- 세트별로 무게·횟수를 ±로 조절하고 [+ 세트 추가]·세트 지우기를 한다. 고정 무게는 바꿀 수 없다.
- 혼자 하는 상한을 넘기면 "그대로 기록되고 다음 PT 때 확인" 안내가 나온다. 상한에 닿으면 "혼자서는 여기까지예요"가 나온다.
- 지난번 아파서 멈춘 종목에는 "트레이너가 확인할 때까지 무게가 그대로예요"가 붙는다.
- 종목마다 [했어요] / [아파서 멈췄어요](건강정보 동의자만, 아니면 "아프면 바로 멈추고 트레이너에게") 버튼이 있다.
- [오늘 못 함]을 누르고 이유 칩(자리 없음·시간 없음·기구 고장·기타)을 고르면 표시되고, [되돌리기]로 취소한다.
- '루틴에 없는 운동도 했나요?'에서 이름을 넣고 [추가]하면 세트별로 적는다(앱이 숫자를 추천하지 않음).
- [오늘 운동 기록하기 (n개)]를 누르면 저장되고, 개인운동 기록(오운완)에도 자동으로 들어간다.
- 오운완 체크만 실패하면 "운동은 기록했어요. 오운완 체크는…" 안내가 나온다.
- 루틴 카드 아래에 안전 안내 문단과 [새 루틴 요청]이 있다.
- 개인운동 기록: 날짜(오늘·어제·그제만)와 '오늘 한 운동'을 적고 [기록]을 누른다.
- 유산소 기록: 날짜(그제까지), 시간(분), 종류, 메모를 적고 [기록]을 누른다.
- 그제보다 이전 날짜를 고르면 "오늘 · 어제 · 그제 기록만 남길 수 있어요"가 뜬다.
- 비포애프터 사진: 분류(비포/진행/애프터)와 날짜를 고르고 [사진 올리기]를 누르면 자동으로 압축해 올린다.
- 저장·삭제가 되면 아래에 잠깐 알림(토스트)이 뜬다(예: "유산소 기록을 저장했어요").
- 남은 수업 0회·지난 회원·센터 기간 끝이면 이 탭 자체가 없다.

### 회원 운동일지 탭
- 맨 위 확인 배너 "확인 안 한 운동일지 n건 · 확인하기 ›"가 있다(홈 탭에도 보임).
- 자동 확인된 수업에는 "자동 확인된 수업 n건 · 서명해 주세요" 띠가 붙는다.
- 운동 달력: 이전·다음 달로 넘기고, 날마다 색 점이 찍힌다(PT 빨강 · 개인운동 주황 · 유산소 파랑). 범례가 있다.
- 달력에서 일요일·공휴일은 빨강, 토요일은 파랑이고, 공휴일 이름은 날짜에 마우스를 올리면 보인다. 오늘은 테두리로 표시된다.
- 기록 있는 날을 누르면 그날 상세(PT 수업·개인운동 메모·유산소 종류·분)가 펼쳐진다.
- '내 운동일지' 목록: 날짜, 누적 회차, 접었을 때 종목 요약 한 줄이 보이고, 가장 최근 일지는 펼쳐진 채로 나온다.
- 확인 상태 뱃지: 미확인 / 트레이너 확인 중('내용이 달라요' 뒤) / 자동 확인 · 서명 전 / 자동 확인 · 서명.
- 일지 본문: "n종목 · m세트", 종목별 표(세트 | 무게 | 횟수, 0kg은 '맨몸').
- 그 종목의 가장 무거운 세트가 지난번보다 늘었을 때만 "지난번보다 ▲ n kg"이 붙는다.
- 트레이너 설명은 저장된 글 그대로 전부 펼쳐 보인다.
- [가가 글씨 크게]를 누르면 일지 글씨가 커진다(이 기기에서만 기억).
- 내용이 없는 일지는 "상세 내용이 없어요" / "수업 기록만 있고 내용은 비어 있어요"로 나온다.
- 아래에 개인운동 기록 목록과 유산소 기록 목록이 있고, 각 항목을 삭제할 수 있다(볼 수만 있으면 삭제 없음).
- 빈 상태 안내: "아직 기록된 운동일지가 없어요", "아직 개인운동 기록이 없어요…", "아직 유산소 기록이 없어요…".

### 회원 내 기록 탭(실제 탭 이름 '변화')
- 인바디 변화: 최근 측정일, 항목별 지금 값과 직전 대비 ▲▼(좋아짐 빨강·나빠짐 장미색), 항목마다 작은 추이 선.
- 종목별 무게 변화: 종목명 · 추이 선 · 최신 무게 · 직전 대비 변화가 한 줄씩 나온다.
- 무게가 오른 종목이 있으면 "무게가 오른 종목이 n개예요. 잘하고 있어요!"가 뜬다.
- 무게 변화는 5개까지 보이고, [나머지 n개 더 보기]로 펼친다.
- 비포애프터 사진 갤러리: 분류·날짜 라벨이 붙고, 누르면 크게 보인다. 삭제 버튼도 있다.
- 빈 상태 안내: "아직 인바디 기록이 없어요", "아직 사진이 없어요. 비포 사진부터 남겨보세요".

### 회원 확인·서명 흐름
- 확인 대상은 수업 시작 1시간 뒤부터다. 미확인이 1건이라도 있으면 페이지를 열 때마다 확인 창이 먼저 뜬다.
- 확인 창은 ✕·바깥 누르기·ESC로 닫히지 않는다. 버튼으로만 고른다.
- 창에 "남은 n건", 수업 날짜, 운동일지 표·설명이 보인다.
- "○월 ○일(요일) 수업을 확인합니다" 문장과 자동 확인 예정 시각("…이 지나면 서명 없이 자동으로 확인돼요")이 나온다.
- 서명 칸에 손가락이나 마우스로 서명하고 [다시 쓰기]로 지울 수 있다. 날짜는 손으로 쓰지 않고 서버가 기록한다.
- 서명해야 [서명하고 확인]이 켜진다(전에는 "서명하면 확인할 수 있어요").
- 밀린 수업이 있으면 "밀린 수업 n개도 같은 서명으로 확인할게요"를 체크하고 날짜별 내용을 펼쳐 본다(한 번에 최대 10건).
- [내용이 달라요]를 누르면 메모 칸(200자, 선택)이 열린다. [트레이너에게 알리기]를 누르면 자동 확인이 멈추고 트레이너 폰에 알림이 간다.
- '내용이 달라요' 화면에서 [돌아가기]로 되돌아간다.
- 트레이너가 고친 뒤에는 "트레이너가 내용을 고쳤어요. 다시 확인해 주세요"와 함께 창이 다시 뜬다.
- [나중에 할게요]는 이번만 닫는다. 다음에 페이지를 열면 다시 뜬다.
- 확인하면 그 일지는 목록에서 빠지고 다음 건이 자동으로 앞으로 온다. 이미 확인된 건은 조용히 정리된다.
- 동의 뒤 수업은 24시간(옛 문구에만 동의한 회원은 48시간) 안에 아무것도 누르지 않으면 자동으로 확인된다.
- 자동 확인된 수업은 나중에 띠 → 시트에서 내용을 보고 한 번에 서명할 수 있다(최대 10건, "확인은 이미 끝났어요").
- 센터 기간 끝·PT 종료면 확인 유도를 끄고 "지금은 기록을 볼 수만 있어요" 한 줄만 보인다.
- 서버 키가 없거나 오류면 유도를 통째로 꺼서 회원을 잠그지 않는다.
- 세션이 끝났으면 "세션이 만료됐어요. 다시 로그인해 주세요", 네트워크 오류면 연결 확인 안내가 나온다.

### 회원 식단
- 트레이너가 식단 관리를 켠 회원에게만 보인다.
- '오늘 식단'에 목표 약 n kcal과 운동한 날·운동 없는 날 구분이 보인다(숫자 없는 회원은 안 보임).
- [사진 추가]를 누르면 사진의 찍은 시각을 먹은 시각으로 채운다. 메모(200자)와 시각을 고쳐 [올리기]를 누른다.
- [글로 남기기]로 사진 없이 메모만 올릴 수도 있다.
- 먹은 시각에 따라 "어제 식단으로 올라가요"가 미리 보이고, 올린 뒤 "어제 식단에 올렸어요" 안내가 나온다.
- 오늘 올린 끼니마다 사진 썸네일 또는 '글', 시각, 메모가 보인다. "피드백 뒤 추가" 표시가 붙을 수 있다.
- 끼니를 지울 수 있다. 피드백 받은 날은 "피드백을 받은 날은 지울 수 없어요"가 나온다.
- [오늘 식단 끝]을 누르면 "트레이너 확인 중이에요. 더 먹으면 계속 올려도 돼요"로 바뀌고 트레이너에게 알림이 간다.
- 피드백이 오면 "오늘 식단 피드백이 왔어요. 홈에서 볼 수 있어요"가 뜬다.
- 하루는 오전 6시에 바뀐다("오늘 식단은 내일 오전 6시까지예요").
- '내 식단 가이드': 목적·n주차/총 주, 운동 없는 날·운동한 날 kcal, 탄수화물·단백질·지방 g.
- 질환이 있는 회원에게는 숫자 대신 "먹은 것을 기록하며 트레이너와 함께 관리해요"가 나온다.
- [예시 식단]을 누르면 AI 예시 3가지(끼니별 메뉴·합계)가 펼쳐진다.
- [식단 짜 주세요] 창: 언제(오늘 남은 끼니 / 이번 주), 상황 칩(회식·편의점·도시락·외식·못 먹는 음식), 메모를 넣고 [트레이너에게 요청하기].
- 요청은 하루 3번까지다. "오늘 요청 n / 3"이 보이고, 다 쓰면 "오늘은 요청을 다 썼어요. 내일 다시 요청해 주세요 🙂"가 뜬다.
- 기다림 문구: 1·2번째는 "수업 중엔 조금 늦을 수 있어요 🙏", 3번째는 "트레이너가 바쁘면 늦을 수도 있어요 😅".
- 답 오기 전에는 [요청 취소]를 할 수 있다. 이미 준비 중이면 "취소할 수 없어요"가 나온다.
- 답은 소개 → 날별 계획 → 팁 → 마무리로 보인다. 지난 답은 "지난 식단 답 n개"로 접혀 있다.
- 홈 피드백 카드: 열량·단백질·탄수화물 막대(넘치면 주황), 잘한 점 / 다음엔 하나만 / 먹은 시간 / 한마디, 트레이너 이름 뱃지.
- 트레이너가 답하지 않으면 페이지를 열 때 AI가 대신 보낸 답·피드백이 이어서 나타난다. 회원 화면에는 AI 표시가 없다.
- 안내 문구: "사진 기준 추정 · 영양 상담이 아닌 참고용 · 트레이너가 AI 분석을 활용해 답할 수 있어요".
- 식단이 꺼졌거나 남은 수업이 없으면 각각 이유를 알려 주는 오류 문구가 나온다.

### 회원 이벤트
- 이벤트 띠를 누르면 상세 시트가 열린다: 기간(또는 상시), 🎁 상품, 챌린지 목표("오운완 n회"), 설명, 정원·참여 인원, 신청 기간.
- [참여하기]를 누르면 참여한다("참여하면 취소할 수 없어요" 미리 안내). 만든 사람과 담당 트레이너에게 알림이 간다.
- 출석 챌린지 참여 중에는 n/m회 진행 막대가 보인다. 달성하면 "달성! 트레이너에게 받으세요 🎉", 받으면 "상품을 받았어요".
- 일반 이벤트는 "참여했어요. 트레이너가 안내해 드릴 거예요" / "혜택을 받았어요"로 나온다.
- 참여 실패 문구: 아직 신청 기간 아님 / 마감 / 정원 다 참 / 지금은 참여할 수 없음 / 이벤트가 끝났어요.
- 끝난 이벤트는 7일 동안 더 보인다. 지난 회원에게는 이벤트가 숨겨진다.

### 회원 예약
- 잡힌 수업 목록(날짜·시간)이 나오고, 없으면 "잡힌 수업이 없어요."가 나온다.
- 수업마다 [시간 바꾸기] / [취소하기]가 있다.
- 수업이 트레이너가 정한 n시간 안으로 다가오면 "앱으로 바꿀 수 없어요. 트레이너와 직접 이야기해 주세요"로 바뀐다.
- [새 수업 요청하기]: 이번 주와 다음 주 날짜 칸, 6~23시 1시간 칸 중에서 고른다.
- 트레이너 일정이 있거나 기준 시간을 지난 칸은 흐리게 막힌다. 고를 수 있는 시간이 없는 날은 날짜 칸도 막힌다.
- 트레이너에게 한마디(선택)를 적고 "○월 ○일 … 요청하기"로 보낸다. 트레이너 폰에 알림이 간다.
- 요청 중에는 "새 수업 요청 · 확인 중"이나 "시간 변경 요청 · 트레이너 확인 중 (→ 새 시간)"과 [요청 취소]가 보인다.
- 결과는 "○○ 요청이 승인됐어요 / 거절됐어요"와 거절 사유로 보이고, [확인]을 누르면 사라진다.
- 오류 문구: 이미 요청함 / 그 시간 안 됨 / 새 요청 3개까지 / 트레이너가 앱 요청 안 받음 / 남은 수업 없음 / 이미 바뀐 수업.
- 트레이너가 요청을 받지 않거나 볼 수만 있는 상태면 잡힌 수업만 보이고 버튼이 없다.
- 안내 문구: "트레이너가 승인하면 예약이 잡혀요. 변경 · 취소는 수업 n시간 전까지".

### 회원 알림
- [켜기]를 누르면 권한을 묻고 이 폰에 알림이 켜진다. 켜지면 시험 알림이 한 번 온다.
- 아이폰 사파리에서는 "홈 화면에 추가해 주세요 · 방법"을 펼치면 3단계 안내(공유 → 홈 화면에 추가 → 아이콘으로 열고 켜기)가 나온다.
- 켜져 있으면 맨 아래에 "폰 알림 받는 중 · 끄기"가 보인다. 권한을 거부했으면 카드가 숨는다.
- 받는 알림: 운동일지 확인, 예약 승인·거절 결과, 새 이벤트, 식단 피드백·답.
- 로그아웃하면 이 기기의 회원 알림도 꺼진다(같은 기기의 트레이너 알림은 그대로).

### 회원 하단·동의·옮기기
- 하단 안전 안내: "통증·어지러움 시 바로 멈추기 · 의료 조언 아님".
- 건강정보 동의 상태(동의했어요 / 동의하지 않았어요)와 [동의 철회] / [동의하기]를 언제든 바꿀 수 있다(기록이 새로 쌓인다).
- 운영 주체("센터명" 또는 "상호 · 이름 트레이너") · 서비스 제공 오직 트레이너 표시가 있다.
- 개인정보처리방침·이용약관 새 창 링크가 있다.
- 맨 아래 [로그아웃]은 이 기기에서만 로그아웃한다.
- 기록 옮기기 동의: 트레이너가 옮겨 가는 곳, 옮겨지는 것(운동일지·인바디·사진·남은 수업), 링크 그대로, 기한 넘기면 안 옮김을 안내한다. 옮기면 새로고침된다.

## 5. 공개 페이지 · 가입 · 로그인 · 결제 화면

### /lp (트레이너용 랜딩 · 로그아웃 상태의 "/"도 같은 화면)

- 후기 구간은 실제 후기 3개가 모이기 전까지 숨겨져 있다.
- '트레이너가 할 일은 이게 다예요': 5단계 흐름(OT 신청 → OT 수업 → PT 수업 → 재등록 → 실적·급여)에 앱 몫과 트레이너 몫이 나뉘어 있고, 아래에 회원·이벤트 한 칸.

- 세일즈북 묶음은 단계 탭(계획·추천 PT·약속), 운동일지 묶음은 말하기 → 앱이 정리 → 회원 폰을 옆으로 넘기며 본다.

- 중간 행동 띠: "신규·재등록 1건만 더 나와도 이용료 회수" + [지금 시작하기].
- 태블릿·PC 화면 갤러리(PC/태블릿 뱃지 7장)가 있다.
- 가격 카드 3장(베이직·프로 추천·센터): 월 금액, 정가 취소선·얼리버드, 하루 약 n원, 기능 목록, [시작하기]. 센터 카드에는 [도입 상담하기](카톡)도 있다.
- 가격 카드 버튼은 고른 요금제를 들고 가입으로 간다(/signup?plan=basic|solo, 센터는 ?type=center).
- 추가 팩 상자: 대본·음성일지·식단 AI 각각 작은 팩과 큰 팩, 단위당 가격, "더 저렴" 표시, 1개월·7일 환불 규칙.
- 결제 조건 안내 줄(부가세 포함 · 월 정기결제 · 7일 전액 환불 · 언제든 해지)과 환불 정책 링크가 있다.
- 검은 상자 "센터 대표님께" → [센터 대표용 페이지 보기].
- FAQ 12개는 펼치기 방식이고, 그 아래 "카카오톡으로 물어보세요" 링크가 있다.
- 만든 사람 소개 → 마무리 [지금 시작하기] / [가입 없이 먼저 눌러 보기] / "월 19,900원부터".

### /center (센터 대표용 랜딩 · 어두운 화면)
- 머리: 같은 전환 스위치, 대표 화면·태블릿/PC·가격·FAQ 앵커, [로그인], [도입 문의](카톡).
- 첫 화면: [센터 도입 문의] / [센터로 시작하기] / "매출이 새는 곳, 1분 무료 진단"(/check?who=owner).

- 대표 화면 묶음 6개(아침 보고서·월간 결산·매출 정산·OT 등록·트레이너 관리·수업 증빙 운영): 큰 폰 화면, 화면 설명, 기능 더 보기 갤러리.

- '트레이너가 편해야' 구간: 체크 4개 + [트레이너용 페이지 보기].
- '도입은 이렇게' 3단계(계정 만들기 → 트레이너 초대 → 회원 등록)가 있다.

- 센터 플랜 가격 상자: 금액, 얼리버드, 하루 약 n원, 포함 기능, [센터 도입 문의] / [센터로 시작하기], 결제 조건 줄.

### /check (1분 무료 진단)
- 시작 화면에서 [트레이너예요] / [센터 대표예요]를 고른다. `?who=trainer|owner` 링크로 바로 시작할 수도 있다.
- 예/아니요 질문이 이어진다(트레이너 8개, 대표 7개). 진행 막대와 n/전체, [이전]이 있다.
- 결과 머리: "회원이 없는 이유 n개" 또는 "매출이 새는 곳 n곳"(못 찾으면 다른 문구).
- 결과 본문: '놓치고 있는 것 → 앱이 챙겨요'(이유 + 해결) / '잘하고 계신 것 → 앱이 시간을 줄여 줘요'.
- 선택 계산기: 한 달 OT 회원 수와 평균 계약 금액(쉼표 자동)을 넣으면 예시 이익이 바로 계산된다(대표는 클로징률 +10%p, 트레이너는 OT 1명 더, 1년치).
- 결과 버튼: 트레이너는 [PT 한 회 값으로 시작하기] / [가입 없이 눌러 보기], 대표는 [15분 시연 요청하기(카톡)] / [센터로 시작하기]. 가격 줄이 붙는다.
- [처음부터 다시 하기]가 있고, "답은 어디에도 저장되지 않아요 · 효과를 약속하지 않아요" 안내가 있다.

### /try (가입 없이 직접 눌러 보기)
- 장면 4개를 칩으로 고른다: QR로 OT 신청 · 회원 이벤트 · 수업 예약 요청 · 운동일지·서명. 주소 `#장면`으로 바로 열린다.
- 트레이너 폰과 회원 폰이 나란히 놓인다. 좁은 화면에서는 위 전환 칩으로 한 대씩 보고, 새 소식이 오면 빨간 점이 붙고 자동으로 넘어간다.
- 한쪽에서 누르면 반대쪽 폰에 알림 배너가 내려온다(3.5초 뒤 사라짐).
- 단계 안내 상자가 있다: 지금 할 것 힌트, 끝난 단계 체크, "끝까지 해 보셨어요", [처음부터].
- QR 장면: 이름, 요일·시간·목표를 고르고 동의를 체크해 [신청하기] → "1분만 더" 안내 → 트레이너 폰에 '새 OT 회원' → 신청서 정보·아직 몰라요 → [1차 OT 잡기].
- 이벤트 장면: 출석 챌린지 제목·목표 횟수·상품을 바꿔 [이벤트 만들기] → 회원이 [참여하기] → 참여 명단에서 [달성 · 지급 완료].
- 예약 장면: 회원이 빈 칸을 골라 요청(트레이너 일정 칸은 흐림) → 트레이너 [승인]/[거절] → 양쪽 일정에 반영.
- 서명 장면: 트레이너가 세트 무게를 ±5kg 바꿔 저장 → 회원이 서명하고 확인 → 트레이너 기록에 서명과 '10월 수업 확인서' 표가 생긴다.
- [다음 체험 · ○○] / [내 회원으로 해 보기]가 있고, "아무 데도 저장되지 않아요 · AI 호출 없음" 안내가 있다.

### /download (설치·시작 안내)
- [앱 설치하기](기기별 설치 창 또는 안내 시트) / [지금 시작하기] / [로그인].
- 기기별 홈 화면 추가 안내 3칸이 있다(아이폰 사파리 4단계, 안드로이드 크롬 3단계, PC·태블릿 3단계).
- '이런 서비스예요' 소개와 체크 4개가 있다.
- 하단 링크(서비스 소개·가격·FAQ·시작하기), 의료기관 아님 고지, 사업자 정보가 있다.

### /join/[code] (OT 신청서 · 공개 · 검색 제외)
- 불러오는 중이면 "불러오는 중이에요"가 나온다.
- 잘못되거나 닫힌 링크면 "이 신청서는 닫혔어요 · 새 링크를 요청해 주세요", 네트워크 오류면 "신청서를 열지 못했어요"가 나온다.
- 트레이너 QR이고 소개를 만들어 뒀다면 맨 위에 트레이너 소개가 나온다: 사진(없으면 첫 글자), 이름·자격, 한 줄 소개, 전문 분야 태그.
- 소개 아래 '이런 변화를 만들었어요' 사례 카드(익명, 실제 기록 그대로)와 [OT 신청하기](신청서로 스크롤)가 있다.
- 머리에 센터명과 "○○ 트레이너가 받아요" 또는 "센터에서 담당 트레이너를 정해 연락드려요" · "30초면 신청돼요"가 나온다.
- 기본 정보: 이름, 휴대폰 번호(형식 확인, "OT 일정을 잡을 때 연락드리는 번호").
- 원하는 요일(7칸)과 시간(6~23시 칸, 여러 개)을 고른다. 요일을 안 골랐으면 "요일을 먼저 골라 주세요".
- 요일이 2개 이상이면 "요일마다 되는 시간이 달라요"를 켜서 요일마다 따로 고르고, "○요일과 같게"로 복사할 수 있다.
- 덧붙일 말(선택 100자)을 적을 수 있다.
- 동의: 개인정보(필수)와 운동일지 확인 방법(필수) 체크박스, 각각 [내용 보기] 펼침, 처리방침 링크.
- 입력 검증 문구: 이름 입력 / 번호 확인 / 필수 동의.
- 서버 문구: "지금 신청이 많아요"(IP 10분 5번·링크 1시간 30건), "이 신청서는 닫혔어요".
- 봇이 채우는 숨은 칸이 있다(채워지면 조용히 버림). 같은 번호로 10분 안에 다시 내면 한 번만 처리된다.
- 신청하면 "신청했어요 · 곧 연락드려요" → '1분만 더'로 이어진다([좋아요, 알려 줄게요] / [다음에 할게요]).
- '1분만 더'는 한 화면에 질문 하나씩이다: 목표+언제까지 → 주 몇 번 → 운동 경험·받아 본 운동 → 그만둔 이유 → 생활·페이스.
- 이어서 건강 체크 → 알게 된 경로 → (센터 QR이면) 원하는 트레이너 성별 → 나이·성별·직업·바라는 점.
- 건강 체크 화면은 건강정보 동의 버튼을 눌러야 열린다: 해당 없어요 / 항목 여러 개, 불편 부위, 부상·수술 이력.

## 7. AI가 하는 일

### OT · 재등록 (`app/api/ot-brief` · phase)
- `first`: 1차 OT 대본(30초 요약 · 입장 첫마디 · 4칸 운동 · 클로징 · 거절 대응 · 추천 근거). 서버가 끝까지 만들어 1차 OT 기록에 저장.
- `second`: 2차 이상 OT 대본(1차 관찰 · 이전 차수 결과 근거 · 지난번 소환 · 증명 동작 · 세일즈북 넘기며 클로징). 앞 차수 결과에 따라 '클로징 우선' · '이번엔 꼭 제안'.
- `salesbook`: 2차 OT 세일즈북. 2차 대본을 저장한 뒤 서버가 이어서 만들고, 2분이 지나도 없으면 화면이 그 자리에서 만듦.
- `reregister`: 재등록 상담 대본(변화 · 출석 · 만족도 · 로드맵 · 숫자 목표 · 다음 목표 · 두 번째 이상이면 지난 약속).
- `reg_salesbook`: 재등록 세일즈북 글(숫자는 앱이 계산 · AI는 글만). 재등록 대본 저장 뒤 서버가 이어서 만듦.
- `roadmap`: 목표 로드맵 초안(케어 탭).
- `inbody`: 인바디 분석 · 회원에게 보여 주기(OT 인바디 칸).
- 모델: 대본(first · second · reregister) = Opus, 나머지 = Sonnet. 대본 · 음성일지 · 인바디 · 로드맵은 AI 월 한도에서 세고, 세일즈북은 원가만 기록.

### 그 밖의 AI
- 음성일지(`app/api/voice-log`): 녹음 → 받아쓰기 → 수업 요약(진행한 머신 · 중량 · 세트 · 핵심 피드백 · 개인운동 주의사항) → 일지 · 종목 · 세트 채우기.
- 장비 큐(`app/api/machine-cues`): 설정 '장비 · 큐'의 [AI 초안 생성].
- 식단(`app/api/diet` · `lib/dietAI`): 끼니 사진 분석 · 하루 피드백 초안 · 식단 요청 답 초안 · 예시 식단 3가지 · 트레이너가 안 하면 대신 보내기.
- 대표 아침 보고서(`app/api/owner-report` · `lib/ownerReportAI`): AI 총평 · 오늘 챙길 코칭(회원 이름은 안 넘김).
- 월간 결산(`lib/monthlyReportAI`): 대표 결산 총평 · 트레이너별 잘한 점 · 보완할 점 · 해 볼 것, 개인 '내 결산'(트레이너 성적표는 규칙 기반 · AI 없음).
- 출력은 서버가 한 번 더 다듬어요(긴 줄표 없애기 등 `lib/tidyText`).

### OT · PT 회원 화면 · 세일즈북
- 세일즈북의 '오늘 해본 운동' 장과 `slideKeys` · `caseAnchor` 설정: 이를 넘기는 화면이 없어 열 수 없음(옛 1차 세일즈북 흔적).
- `ClosingSequence`의 상자형(compact 아닌) 화면과 `sweetener` · `icon` 설정: 실제로는 compact 모양만 씀.
- `AIBriefBlock`의 '데모' 상태: 이 화면들 어디에서도 쓰지 않음.
- `SecondOTTab`의 하드코딩 데모 화면: 데모 모드(키 없음)에서만 보임. `?d3=1`은 개발용.
- `MemberAppLink`의 '회원 페이지가 꺼져 있어요…'(지난 회원 · 링크 없음) 문구: 지난 회원 화면이 링크가 있을 때만 이 부품을 보여 줘서 나오지 않음.
- `MemberViewShell`의 목록 표시 분기: `MemberScreen`이 늘 꺼서 넘기므로 쓰이지 않음.
- 재접근 날짜 입력(`ReapproachDateField`)은 PT 재등록 '생각해 본대요'에서만 씀. OT 피드백은 자체 칩 날짜를 씀.
- `InbodyAnalysis`(AI 인바디 분석 화면)는 OT 인바디 칸에서만 보임. PT 화면엔 분석이 없음. 다른 사용처는 숨겨진 체형평가.
- `lib/handover`(회원 넘기기)는 대표 운영 탭 전용이라 트레이너 회원 화면에서는 노출되지 않음.
- `SecondOTTab` 주석에 있는 '세일즈북 만들기' 버튼은 실제로 없음. 클로징의 [세일즈북 열기]가 그 자리에서 만드는 방식으로 바뀜.
- `DeckList` 주석에 'OT 대시보드에서 연다'고 적혀 있지만 실제로 여는 곳은 `DeckList`와 `SecondOTTab`뿐.
- 재등록 세일즈북(`RegSalesbookView`)엔 트레이너 소개 장이 아직 없어요(2차 OT 세일즈북에만 있음).

### 대표 화면
- '한눈에'(`overview`)는 위쪽 메뉴 · 왼쪽 메뉴에 없어요. 폰 홈 타일이나 `?tab=overview`로만 열려요. PC에서는 넓은 홈 안에 이미 들어 있어요.
- `OwnerBriefing`은 `onGoTab`을 받기만 하고 쓰지 않아요. 그래서 보고서 탭에서 다른 탭으로 가는 링크가 없어요.
- 빈 상태 안내 문구에 홈 · 한눈에 · 월간 결산용 줄이 없어요. 이 세 화면에서는 기본 문구가 떠요.
- 쓰는 곳이 없는 코드: `lib/expenses.js`의 `expensesByCategory`, 그리고 `lib/income.js`의 `INCOME_KINDS` · `incomeByKind`(그 파일 안에서만 쓰여요).
- `app/admin/page.jsx`가 불러오는 컴포넌트는 전부 실제로 화면에 나와요. 안 쓰이는 컴포넌트는 없어요.
- 매출 목표는 대표가 정할 수 없어요. 트레이너가 '내 실적'에서 정한 값만 합산되고, 대표 화면에서는 보기만 해요(월간 결산 추천 목표도 보기 전용).
