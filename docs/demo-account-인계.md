## 남은 일 1 — 실제 AI 돌리기 (스크린샷 회원만)

로컬 개발 서버(`preview_start` name `dev` → `http://localhost:3000`)에서 데모 계정으로 로그인해 **실제 화면의 AI 버튼**을 누른다.
(로컬 개발 서버 + 이 세션에서 만든 테스트 계정이라 테스트 로그인 허용 범위.)

박준형(`trainer1`)으로:
| 회원 | 위치 | 할 일 |
|---|---|---|
| 이서준 (OT · 1차 대기) | OT › 1차 OT 준비 | AI 사전무장 생성 |
| 김민지 (OT · 1차 끝, 2차 오늘) | OT › 2차 OT 준비 | AI 브리핑 생성(케이스 거울 포함) |
| 박하은 (PT · 잔여 3) | PT › 재등록 준비 | AI 재등록 브리핑 생성 |
| 박하은 | PT › 회원자료 › 인바디 | AI 분석 |

대표(`owner`)로: 대표 화면 › 오늘 챙길 것 → 운영 보고서 자동 생성 확인.

**음성 운동일지는 대표가 직접 녹음**(최준호 · PT › 자료남기기 · 30초 2~3개). AI 결과를 손으로 지어 넣지 않는다.

## 2026-10-06 촬영 준비 — 날짜 옮기기 · 새 기능 채우기 · 아침 보고서

**촬영하는 날 아침마다(또는 시연 전) 이것부터:**
```bash
node --import ./scripts/demo/alias-loader.mjs scripts/demo/shift-to-today.mjs --write
node --import ./scripts/demo/alias-loader.mjs scripts/demo/report-today.mjs --write
```
- `shift-to-today` = 데모 센터의 모든 날짜를 '오늘' 기준으로 N일 옮김(SQL 함수 `demo_shift_days` · `docs/migrations/2026-10-06-demo-shift.sql` · 대표 주소가 데모 주소인 센터만 · 서버 키로만). **AI 결과 · 서명 · 기록은 그대로** → 다시 만들 필요 없음. 기준일은 `.demo-credentials.json`의 `anchorDate`. 확인 · 서명 해시는 새 수업 시각으로 다시 계산 · 내일 이후 날짜가 된 아침 보고서는 지움.
  ⚠️ 기준일보다 뒤에 실제로 만든 행(예: 그날 시험한 신청서)도 같이 밀린다 → 시험은 옮긴 뒤에.
- `report-today` = 오늘 아침 보고서를 AI 총평까지 다시 만들어 저장(아침 작업과 같은 함수 · AI 1회 · 알림 없음).
