# 제품 정의 재정렬 — 리텐션·자동화 중심 (2026-07-21)

> **방향 전환:** "AI 세일즈 플랫폼" → **"트레이너 업무 서포터 — 회원 리텐션 + 업무 자동화."** 세일즈(재등록)는 *주인공*에서 *결과·조력*으로 위상 변경(버리지 않음).
> **이 문서의 지위:** 포지셔닝 정본. 아래 §1~§4를 **MASTERPLAN §1 · PRD §1.1~1.4**에 반영하고, 브랜드/마케팅 메시지를 여기에 정렬한다. ⚠️ **CLAUDE.md의 'OT 지원 AI 대전제'(세일즈 클로징 극대화)는 유지** — 그건 제품 전체 목적이 아니라 *OT 브리핑이라는 한 기능의 로컬 목적*이다.

---

## 1. 한 줄 정의

**오직 트레이너** — 트레이너가 **'수업의 질'에만 집중**하도록, **회원 관리·기록·행정을 앱이 대신 짊어지는** AI 서포터. 회원은 회원앱에서 **스스로 자기 운동 콘텐츠를 쌓으며 꾸준히 붙어있고(리텐션)**, 트레이너의 잡무는 **80%+ 사라지며**, 재등록은 만족의 **자연스러운 결과**로 따라온다.

> **브랜드명 재해석:** "오직 트레이너"는 이제 "트레이너 전용"을 넘어 — **트레이너는 오직 수업(트레이닝)에만, 나머지는 앱이.** 이름과 정의가 일치한다.

**핵심 인과(제품의 논리):**
회원 자율 참여 → 리텐션 ↑ → PT 만족도 ↑ → **재등록은 밀어붙이지 않아도 자연히.** 동시에 수업일지 자동화 → 트레이너 잡무 80%↓ → 수업 퀄리티 ↑ → 만족도 ↑ (같은 루프를 강화).

---

## 2. 해결하는 문제 (재정의)

> 기존 PRD §1.2는 문제를 전부 *세일즈*(저항·클로징·거절공포)로 봤다. 실제 트레이너의 더 큰 고통은 **잡무 과부하 + 손 많이 가는 회원 관리**이고, 재등록 실패는 그 결과다.

| 문제 | 현장에서 벌어지는 일 |
|---|---|
| **개별 관리 과부하** | 회원 한 명 한 명 챙기다 시간·에너지 소진 → 정작 붙잡아야 할 회원을 못 챙김 |
| **잡무가 본업을 잡아먹음** | 수업일지·기록·정산·확인에 시간 뺏겨 수업 준비·질이 밀림 |
| **안 보이는 성장 = 약한 리텐션** | 회원이 자기 변화를 못 느끼면 조용히 이탈 → 재등록이 '설득'이 됨 |
| 재등록 타이밍 누락 | 잔여 세션이 끝나가는 걸 뒤늦게 알아챔 |
| 기록의 증발 | 1차에서 본 것을 2차에서 못 씀 · 매번 처음부터 |

---

## 3. 해결 방식 — 4개 기둥

| 기둥 | 제품에서의 구현(기존 자산 포함) |
|---|---|
| **① 회원 리텐션 (자율 참여)** | 회원앱에서 회원이 **스스로** 기록을 쌓는다 — 운동일지 확인·**오운완**(연속 출석·포상)·비포애프터 사진·유산소·스케줄·인바디. 트레이너가 일일이 안 챙겨도 회원이 붙어있다. |
| **② 업무 자동화 (80%↓)** | **음성 수업일지 AI 요약**(말하면 일지 완성)·**수업확인 서명 자동화**·잔여/재등록 **타이밍 자동 감지**·**오늘 할일 자동 도출**(재접근·미확인·미처리 예약). 손으로 하던 기록·관리·행정을 앱이 대신. |
| **③ 수업 퀄리티 집중** | ①②가 잡무를 걷어내니 트레이너는 **수업의 질**에만 집중 → 만족도가 오른다. |
| **④ 재등록 = 결과** | 만족·리텐션의 자연스러운 귀결. 기존 **OT/재등록 지원(사전무장·당위성 브리핑)은 유지**하되 "밀어붙이는 세일즈"가 아니라 **이미 만족한 회원에게 재등록 당위성을 자연스럽게 보여주는 조력**으로 재배치. |

---

## 4. 하지 않는 것 (기존 유지 + 새 정의에 맞춰 강화)

- **트레이너 대신 판단하지 않는다** — 관찰 입력 건너뛴 자동 생성 없음.
- **의료 영역 침범하지 않는다** — 진단·치료·교정 금지.
- **수치를 처방하지 않는다** — 세트·횟수·중량·각도는 방향·원리만.
- **성과를 보장하지 않는다** — 매출·체중 숫자 약속 없음.
- **회원을 압박하지 않는다** — 허위 긴급성·기한 조작·죄책감 유도 금지(AI 프롬프트 단계 차단). ★새 정의와 특히 정합.
- **★트레이너를 세일즈맨으로 만들지 않는다** — 재등록은 **만족의 결과**지 강매가 아니다. 앱은 회원이 스스로 붙어있게 만들어 재등록을 *쉽게* 하지, 트레이너에게 판매를 *강요*하지 않는다.
