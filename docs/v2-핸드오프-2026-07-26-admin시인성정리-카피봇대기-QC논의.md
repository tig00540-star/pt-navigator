# 인계서 — 오직 트레이너(pt-navigator) · admin 시인성 정리(분석5탭) + 카피봇 정직화(대기) + QC/사전확인 논의 (2026-07-26)

> **범위:** 관리자 페이지 실사용하며 시인성 정리. 분석 5탭(트레이너·매출·전환·리텐션·스케줄)에 **"결론 숫자+챙길 대상 먼저, 근거는 접기" 리듬**을 통일 적용(탭별 1커밋, 리뷰 통과). 부수로 매출 6개월 추이 폰 겹침 수정, 트레이너 탭 워딩('내가'→'센터가'). **카피봇 정직화는 스펙만 작성·구현 대기.** QC 탭·AI 카피봇 승격·"사전 준비 확인 버튼" 방향 논의(코드 없음). 새 채팅 맨 위에 이 파일 붙여 이어간다.
> ⚠️ **먼저:** `git --no-pager log --oneline -10`으로 아래 5개 refactor 커밋이 어디까지 들어갔는지 확인(대수가 순차 커밋 중이었음).

## 협업 방식 (그대로)
- **웹Claude:** 수정 스펙 작성 + 코드 리뷰(코드 내용 매칭·라인번호 X) + 순수함수 실행검증. **앱 코드 직접 안 씀.**
- **CC:** 로컬 구현. **대수:** `git diff` 붙여넣기 → 웹Claude 리뷰 → **커밋은 대수**.
- **제약:** additive 우선 · 로직/RLS/payload 불변 기본(변경 시 명시) · 새 파일 `git add` 먼저 · **배치별 1커밋** · Windows PowerShell(`npm.cmd run build/lint`).
- ⚠️ **`lib/memberStatus.js`는 마운트 캐시로 재스테이징해도 옛 스냅샷** → 그 파일 리뷰는 대수가 `git diff` 붙여넣기로.
- ⚠️ **이번 세션 디바이스 브릿지가 중간에 끊김** → 스펙들을 `docs/`에 못 저장하고 **채팅 파일카드로만 전달**. 새 세션에서 필요하면 스펙을 `docs/`에 저장할 것.

## 이번 세션 완료 — 분석 5탭 시인성 정리 (각 1커밋 · 전부 리뷰 통과)
공통 패턴: 각 탭에서 무거운 "근거" 블록을 **접기 토글**(기본 닫힘 · `const [detailOpen,setDetailOpen]=useState(false)` · lucide `ChevronDown/ChevronRight` · 동일 버튼 마크업)로 감쌈. **`useMemo` 계산은 그대로 돎(렌더만 지연) → 수치·로직·payload 불변.**

1. **트레이너 탭** `app/admin/page.jsx` — 커밋 `refactor(admin): 트레이너 탭 위계 정리(클로징·재등록 분석 접기 + 워딩 '센터가')`. '클로징·재등록 분석' 4블록 접기 + 워딩 "내가 주로 놓치는 이유"→"센터가 주로 놓치는 이유". (상태 `perfDetailOpen`)
2. **매출 탭** `components/admin/RevenuePipeline.jsx` — 커밋 `refactor(admin): 매출 탭 근거 접기 + 6개월 추이 라벨 만원 축약(폰 겹침)`. 구성비·6개월추이 접기 + 추이 막대 라벨 `won()`(1,240,000원)→`manLabel`(124만) **모듈 헬퍼 추가**(hover `title`엔 원값 유지) + 캡션 "만원 단위" 명시.
3. **스케줄 탭** `components/admin/ScheduleAnalytics.jsx` — 커밋 `refactor(admin): 스케줄 탭 근거 접기(히트맵·트레이너표)`. 밀도 히트맵·트레이너 스케줄표 접기. **4타일·미처리 예약 리스트는 유지.**
4. **리텐션 탭** `components/admin/RetentionConsole.jsx` — 커밋 `refactor(admin): 리텐션 탭 근거 접기(트레이너별 재등록률)`. 맨 아래 재등록률 카드만 접기. ⚠️ diff에서 옛 `{/* 4) … */}` JSX 주석이 `&&()` 안으로 들어가며 `/* … */` JS 주석으로 바뀐 게 정상(유효) — **build green 확인 권장이라 했음**.
5. **전환 탭** `components/admin/ConversionFunnel.jsx` — 커밋 `refactor(admin): 전환 탭 근거 접기(트레이너별 퍼널 표)`. 트레이너별 퍼널 표 접기. **깔때기·이번주 클로징 임박은 유지.**

→ 5탭 모두 "요약 타일/핵심 결론 + 액션 리스트" 먼저, 상세는 "펼치기"로.

## 대기 — 카피봇 정직화 (스펙 완료 · 구현 안 됨) ★다음 최우선
- **스펙 전달됨(채팅 카드):** `v2-스펙-admin카피봇-정직화-빈상태.md`. 대상 `app/admin/page.jsx`(카피봇 ops 섹션 + `aggregate()`), 1커밋 예정.
- **문제:** ① 회원 0~소수 센터에서 `aggregate` fallback("센터 인근 오피스텔·무릎 통증·IT 개발자")이 칩에 실측처럼 노출 + "회원 0명 분석"(모순). ② "AI 상권 공략 카피봇·DB 빅데이터 기반 자동 생성"=과장(실제는 정적 템플릿 5종 회전).
- **해결(7개 변경):** aggregate에 `hasResidence/hasPain/hasJob` 플래그 additive → `MIN_COPY_MEMBERS=5` 상수 → `copyDataReady=agg.total>=5 && (hasResidence||hasPain||hasJob)` → 제목 "AI 상권 공략 카피봇"→"상권 공략 카피 초안" → 칩 블록 분기(충분: 실값 칩만 · 부족: "예시" 뱃지+"일반 템플릿" 고지) → 카드하단 "DB 빅데이터 기반 자동 생성"→`copyDataReady?"회원 데이터 기반 초안":"예시 템플릿"` → 안내문 "정해진 템플릿+회원분포 초안(AI 생성 아님)".
- **미완:** CC 구현 → diff 리뷰 → 커밋. **여기부터 이어가면 됨.**

## 논의만 함 (코드 없음 · 결정/방향)
- **카피봇 구조:** 고정 템플릿 5종을 3장 창으로 `+1 시프트` 회전(누를수록 2/3 겹침, 5번이면 한바퀴). AI 아님.
- **AI 카피봇 승격(보류):** 승격 시 "센터 고객 진단 1줄 + 채널별 맞춤 카피(근거 포함) + 진짜 재생성"으로 바뀜. `ot-brief` 패턴(Sonnet·캐시·데모폴백). 값어치=입력 데이터 풍부도에 달림. **의료/과장 가드 필수.** 별도 스프린트. (원하면 목업 HTML 1장 제안한 상태.)
- **QC 탭:** 전부 하드코딩 데모(`TRAINERS` 상수). **이미 "예시" 배너 있어 신뢰사고 아님.** 목적(트레이너 감시)이 **실측 리더보드와 중복** → **제거 후보(9탭→8탭).** 제거 시 `ATABS`의 qc·QC 섹션·`TRAINERS` 상수 걷어내면 됨(국소).
- **QC 3지표 실측 가능성:** 조회율→**"사전 열람률"로 실측 가능**(이벤트 로깅) · 대본 리딩률→"열람"까지만 가능(라벨 바꿔야) · 수업 이행률→**불가**(처방 계층 부재 · 비처방 정책 충돌).
- **★대수 채택 방향 — "수업 10분 전 사전 준비 확인 버튼":** 수동 열람 추적 대신, 예약 10분 전 트레이너 '오늘/할일'에 **회원 준비정보(통증·주의·지난수업) 카드 + "숙지 완료" 버튼** → append-only 기록 → **"사전 준비 확인율"** 실측. `workout_log_confirmation` 패턴 재사용(구현 간단). 넛지 효과(측정+행동개선). ⚠️ **확인 카드에 준비정보 실제 노출 필수**(맹목 탭 방지) · 라벨 "숙지 보장" 금지 "사전 준비 확인" · 예약시각 정확성 의존 · 마이그레이션 필요 = **별도 스프린트**. 스펙 아직 안 씀.
