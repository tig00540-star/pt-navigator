## 결정·규율 (반드시 유지)
- **★hidden 필터 = 컴포넌트 책임.** admin은 `user_table.select("*")`로 hidden(환불) 포함 로드 → **컴포넌트가 `visible = members.filter(m=>!m.hidden)`로 걸러 회원기반 함수 전부에 넘긴다**(churn·expiring·funnel·memberTrainer·담당수). 안 하면 이탈·전환에 환불 회원 새고 트레이너 화면과 불일치. (배치 리뷰에서 실제 재현·확정.)
- **색:** 우수=`text-cyan-700` · 주의=`text-danger-text`(rose). DS 초록제거 정책 준수(성과 good을 emerald로 쓰지 않음). 퍼널 단계막대만 OT흐름(amber→primary) 예외. 정적 리터럴만(purge).
- **퍼널 약점 판정:** "2차 성공률↓"는 `secondSuccess/second`(실측)로. `confirmed/second` **프록시 금지** — 1차 즉등록자가 분자에 섞여 나쁜 2차 클로저를 가림(테스트로 재현).
- **임계값은 컴포넌트 상단 상수**(`TH`/`convGrade`) — 원장 조정 가능. 색 판정 최소표본(`MIN_N`) 미만은 neutral.
