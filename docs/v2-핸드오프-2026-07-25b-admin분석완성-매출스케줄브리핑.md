## 결정·규율 (반드시 유지)
- **★hidden 필터 = 컴포넌트 책임.** 회원기반 함수엔 `visible = members.filter(m=>!m.hidden)` 넘김. **계약기반(매출·환불·구성비)·예약기반(히트맵·outcome)은 원본**(회계·트레이너 이력). 노쇼 `memberTrainer`는 **전체 회원**으로 구성(hidden 포함 · 트레이너 이력).
- **색:** 기회/우수=`text-cyan-700` · 위험/환불/주의=`text-danger-text`(rose) · 매출게이지/밀도=`bg-primary`(밀도는 inline style 불투명도). **DS 초록제거 — emerald 금지.** 정적 리터럴만(purge · inline style은 예외).
- **KST 일관:** appointment `start_at`은 UTC — 히트맵·미처리 리스트 모두 **+9h 보정** 후 요일/시각 판정(어긋남 금지 · `ScheduleAnalytics`의 `kstTime` 헬퍼).
- **추정/정직 캡션:** 예측·예상매출은 "추정" 명시 · 밀도는 "가동률 % 아님(정원 데이터 없음)" · 노쇼는 "수업일지 기준(예약 아님)". 표본 부족 = "—"·후보 미생성. no-data ≠ 주의.
- **브리핑 임팩트 랭킹:** 재등록/클로징=명수×평균계약 · 이탈=방치세션×회당단가 · 목표=진도 대비 부족액 · 미처리=건수×회당단가×0.4(위생 하향) · 주의트레이너=표본≥5에서 완료율<50%/노쇼율>15% 최악 1명. impact ₩ 내림차순 top3.
