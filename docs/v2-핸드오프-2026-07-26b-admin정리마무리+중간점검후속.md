## 결정 사항 (코드 아님 · 방향)
- **카피봇:** 정직화 대신 **완전 제거**(과장 표현·얇은 기능·브랜드 "과장 없이"와 충돌). AI 카피봇 승격은 별도 스프린트 보류(git 히스토리로 복원 가능).
- **QC 탭:** 완전 제거(데모·중복). 진짜 대체재 = **"수업 10분 전 사전 준비 확인 버튼"**(회원 준비정보 카드+숙지완료 → append-only → "사전 준비 확인율" 실측 · `workout_log_confirmation` 패턴 재사용). **별도 스프린트 신규 기능** — 아직 스펙 없음.
- **#2 KST — 의도적 보류.** 전원 KST 기기 베타엔 **실피해 0**(잠복) · 제일 큰/위험한 수정(예약 **저장** 경로). ScheduleBoard는 전부 기기 로컬(KST 전제), admin은 강제 +9 → 비-KST 기기에서만 불일치. **비-KST 환경(해외 원장·출장·타TZ 데모)이 실제로 생기면 착수.** 착수 시: KST 기기 저장분은 강제-KST 읽기가 **no-op**이라 데이터 마이그레이션 불필요 · 관건은 "KST 결과 수정 전후 **회귀 무변**" 검증 + `lib/date.js`에 KST 헬퍼 추가(현재 `kstToday`만).
