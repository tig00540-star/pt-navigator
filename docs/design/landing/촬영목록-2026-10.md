# 랜딩 촬영 목록 · 영상 대본 (2026-10-06)

데모 센터 **오트 강남점** · 대표 겸 트레이너 **오직이** 한 계정으로 트레이너 화면과 대표 화면을 다 찍는다. 회원 이름은 전부 지어낸 이름(나개근 · 탁고민 …).

## 0. 찍기 전에 (매번)

1. 날짜 맞추기(촬영하는 날 아침 · Claude에게 "데모 오늘로 맞춰 줘"라고 해도 됨)
   ```
   node --import ./scripts/demo/alias-loader.mjs scripts/demo/shift-to-today.mjs --write
   node --import ./scripts/demo/alias-loader.mjs scripts/demo/report-today.mjs --write
   ```
2. 폰: **라이트 모드** · 글자 크기 기본 · 방해 금지(알림 배너 안 끼게) · 배터리 넉넉히(상태 표시줄은 잘라 내니 신경 안 써도 됨)
3. 데모 대표 계정(오직이)으로 로그인 · **배포본**(onlytrainer.co.kr)에서 찍기 — 개발 서버 아님
4. **폰 화면 전체로 찍어서** `docs/design/landing/shots-2026-10/`에 번호 이름(T01.png …)으로 넣으면, Claude가 4:5(1080×1350)로 카드만 잘라 크게 만든다. 직접 자를 필요 없음.
5. 화면이 다 뜬 뒤 1~2초 있다가 찍기(데이터가 한 번 더 그려짐).

⚠️ **상태가 바뀌는 촬영은 맨 마지막에**(V6 수업 요청 승인 · V8 배정 · V5 서명). 한 번 누르면 데모가 바뀐다 → 다시 찍으려면 Claude에게 "되돌려 줘".
