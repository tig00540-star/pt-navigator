## 1. 무엇을 만드나

**오직 트레이너**(ONLY FOR TRAINER)의 공개 랜딩페이지 한 장.
PT 트레이너의 수업 밖 업무(OT 세일즈 준비·운동일지·재등록·회원관리·정산)를 AI 앱이 대신하는 서비스다.

- **목표 행동:** "7일 무료로 시작" 버튼을 누르게 한다. (보조: 센터 대표는 "센터 도입 문의")
- **두 종류의 방문자**
  - **개인 PT 트레이너** — 주 방문자. 폰으로, 수업 사이 짧은 틈에 본다. 읽을 거리를 싫어한다.
  - **센터 대표** — 트레이너 여러 명을 둔 헬스장 대표. 매출·등록·이탈을 숫자로 보고 싶어 한다.
- **화면 우선순위:** 폰(375px) 먼저, PC(1280px)는 그다음.

## 2. 지금까지의 피드백 — 이 선을 지켜야 한다

| 버전 | 대표의 반응 | 교훈 |
|---|---|---|
| 처음 랜딩(약 4,000자) | "글자가 너무 많아서 대부분 안 읽어봐. 읽는 데 피로감" | 문단을 쓰지 말 것 |
| 2,100자로 줄인 판 | "글자가 너무 많고 한눈에 어떤 앱인지 알아보기 힘들어" | 첫 화면에서 정체가 보여야 함 |
| 1,250자로 확 줄인 판 | "너무 아무 내용이 없는데?" | 기능마다 '무엇을 해주는지'는 있어야 함 |
| **현재(약 1,930자)** | — | 기준선: 기능마다 **제목 + 짧은 줄 2~3개 + 실제 화면** |

**밀도 기준:** 문단 0개. 모든 설명은 한 줄짜리(체크 목록·흐름 칩). 기능마다 제목 두 줄 + 흐름 칩 3개 + 효과 3줄 + 앱 화면.

- 3D 캐릭터·근육 사진·네온.

## 4. 브랜드 — 정확한 값

**이름:** 오직 트레이너 — 워드마크는 "오직"(먹색) + "트레이너"(레드). 심볼은 원 안에 위를 가리키는 레드 삼각형 + 가운데 점.

**색 (이 값만 사용)**

| 역할 | 값 |
|---|---|
| 페이지 배경(연회색) | `#f1f2f6` |
| 카드·흰 바탕 | `#ffffff` |
| 눌린 패널 | `#e8eaf0` |
| 구분선 | `#dfe2ea` / 진한 선 `#cbd2dd` |
| 본문(먹색) | `#13151b` |
| 보조 글자 | `#475569` |
| 흐린 글자 | `#5b6675` |
| 브랜드 레드(채움·버튼) | `#dc2626` |
| 레드 글자(흰 바탕 위) | `#b91c1c` |
| 레드 옅은 바탕 | `#fef2f2` |
| 검정 구간 위 강조 | `#fca5a5` |

- **레드는 누르는 곳과 핵심 강조에만.** 넓은 면적을 레드로 칠하지 않는다.
- **금액·성과를 초록으로 칠하지 않는다.**

**글꼴:** Pretendard 한 벌(굵기·자간으로만 위계). 제목 800~900 · 자간 -0.04em 안팎. 본문 400~500. 다른 글꼴 추가 금지.

**한글 줄바꿈:** 단어 중간에서 끊기지 않게(`word-break: keep-all`).

## 5. 절대 하지 말 것

- 그라데이션(보라·파랑 포함 모든 그라데이션), 글로우, 유리 효과, 네온
- 이모지
- 아이콘 + 제목 + 설명을 담은 **같은 크기 카드를 격자로 늘어놓는 구성**(흔한 AI 랜딩 패턴)
- 카드 안에 카드
- 섹션마다 01 / 02 / 03 번호
- 크림색 배경 + 세리프 제목(AI 랜딩 클리셰)
- 튕기는(바운스) 애니메이션
- **없는 증거를 지어내기** — 후기·고객사 로고·성과 수치·사용자 수. (아직 베타라 확보된 것이 없다. 자리가 필요하면 `[실제 후기]`처럼 빈칸으로 표시)
- 허위 긴급성("오늘만", 카운트다운)
- 의료 표현(치료·교정·진단)

## 6. 섹션 구성과 확정 카피

> 카피는 현재 배포본 그대로다. **바꾸고 싶으면 바꾼 곳을 따로 표시**해 달라(대표 확인 후 반영).

### ① 헤더 (스크롤해도 위에 고정)
- 왼쪽: 심볼 + "오직 트레이너"
- PC 가운데: 기능 · 대표님께 · 가격 · 자주 묻는 질문
- 오른쪽: "로그인"(글자 버튼) · **"무료로 시작"**(먹색 버튼)

### ② 첫 화면
- 제목: **수업만 하세요.** / **나머지는 앱이 합니다.**(둘째 줄 레드)
- 한 줄: OT 준비부터 운동일지·재등록·정산까지, 트레이너의 수업 밖 업무를 앱이 맡습니다.
- 버튼: **7일 무료로 시작 →**(레드) · 앱처럼 설치(흰 바탕 테두리)
- 작은 글: 설치 없이 폰에서 바로 · 7일 무료 체험
- ⚠️ 첫 화면은 **스크롤 효과 없이 처음부터 보여야 한다**(빈 화면 금지).

### ③ 숫자 띠 (연회색 바탕)
| 숫자 | 설명 |
|---|---|
| 30초 | 말로 남기는 운동일지 |
| 5분 | AI와 끝내는 OT 준비 |
| **0건**(레드) | 놓치는 재등록 |

> 참고: "0건"은 약속처럼 읽힐 수 있어 대표가 다른 표현을 고민 중이다. 대안이 있으면 제안해도 좋다.

### ④ 왜 필요한가
- 제목: **수업은 2시간,** / **수업 밖 업무는 4시간.**(레드)
- 한 줄: 일지·상담 준비·재등록 챙기기. 실력이 아니라 시간을 먹는 일들을 앱에 넘기세요.
- 전 → 후 4줄 (전은 취소선, 후는 굵게 + 레드 화살표)
  - 일지·기록에 매일 40분 → **말로 30초**
  - OT 준비는 매번 백지에서 → **AI가 대사·근거까지**
  - 재등록은 기억력에 의존 → **앱이 먼저 알림**
  - 회원이 늘수록 관리도 두 배 → **회원이 셀프로 관리**

### ⑤ 기능 4개 — 각 행 = 작은 라벨 · 제목 두 줄 · 흐름 칩 · 효과 3줄 · 앱 화면
흐름 칩은 `A › B › C` 형태로, 마지막 칩만 먹색 채움(= 앱이 끝내주는 지점). **폰 폭에서 칩 3개가 한 줄에 들어가야 한다.**
PC에서는 글 | 앱 화면을 **행마다 좌우 교차**.

| 라벨 | 제목 | 흐름 칩 | 효과 3줄 | 앱 화면 |
|---|---|---|---|---|
| 운동일지 | 쓰지 말고, / 말하세요. | 수업 › 말로 복기 › 회원에게 전송 | 운동별 무게·횟수·세트를 알아서 정리 / 회원에게 보낼 일지까지 한 번에 / 세션 차감·출석 기록도 자동 | 운동일지 녹음·정리 화면 |
| 신규 OT · 세일즈 | 세일즈 잘 모르겠으면, / 따라만 하세요. | OT 보고서 › 클로징 멘트 › 거절 대응 | 회원 정보로 만드는 맞춤 OT 진행 순서 / 수업 직전 3분, 바로 말할 클로징 멘트 / 가격·'생각해볼게요' 등 거절 5가지 대응 | OT 보고서·세일즈북 화면 |
| 재등록 | 재등록 시기, / 앱이 먼저 알려줘요. | 만료 임박 알림 › 변화 근거 › 제안까지 | 잔여가 줄어든 회원을 '오늘 챙길 것'에 먼저 / 인바디·운동일지로 그동안의 변화 정리 / 재등록 제안 멘트까지 준비 | 재등록 알림 화면 |
| 회원 전용 페이지 | 붙잡지 마세요. / 회원이 스스로 챙깁니다. | 링크 하나 › 기록 열람 › 출석 챌린지 | 설치 없이 링크로 여는 회원 전용 페이지 / 운동일지·인바디·변화 그래프를 회원이 직접 / 출석이 쌓이는 오운완 챌린지와 포상 | 회원 전용 페이지 화면 |

그 아래 한 줄: "그리고 수업 밖 나머지도" + 칩 5개 — 급여 자동계산 · 스케줄·노쇼 · 운동 라이브러리 · 내 실적 리포트 · 센터 공지

### ⑥ 센터 대표님께 (이 구간만 먹색 `#13151b` 바탕, 흰 글자)
- 라벨: 센터 대표님께 (`#fca5a5`)
- 제목: **감으로 보던 센터를,** / **숫자로 봅니다.**
- 한 줄: 매출은 월말에야, 이탈은 회원이 떠난 뒤에야 알던 일을 먼저 보여드려요.
- 버튼: **센터 도입 문의 →**(흰 바탕 버튼)
- 2행 (글 | 앱 화면, 좌우 교차)
  - **센터 숫자를 / 한 화면에서.** — 이달 매출과 목표 달성률, 다음달 예상 / 정산 — 매출·지출·순이익을 기간별로 / 트레이너별 등록률·재등록률·성과 → 대표 매출 화면
  - **오늘 챙길 것, / 아침에 바로.** — 이탈 위험·재등록 대상 회원을 급한 순서로 / 오늘 신규 OT 예정과 명단 / 트레이너 코칭까지 담은 AI 운영 보고서 → 대표 '오늘 챙길 것' 화면

### ⑦ 가격 (연회색 바탕)
- 제목: 7일 무료로 먼저 써보세요. / 한 줄: 신규·재등록 **1건만 더** 나와도 회수됩니다.
- 카드 2장 (금액은 실제 결제 금액과 같아야 함 — 바꾸지 말 것)

| | 솔로 (추천 표시) | 센터 |
|---|---|---|
| 대상 | 개인 트레이너 1인 | 트레이너 3인 + 대표 1인 |
| 월 금액 | **59,000원** (정가 79,000원 취소선 · "얼리버드") | **149,000원** (정가 199,000원 · "얼리버드") |
| 포함 | 1·2차 OT · 재등록 서포트 / 음성 운동일지 · AI 리포트 / **회원 전용 페이지 (성과 그래프·비포애프터)** / 실적 · 급여 자동계산 | 솔로 전체 포함 / **대표 대시보드 (매출·정산·등록·이탈)** / 트레이너 3인 좌석 + 대표 1인 / 트레이너 코칭 · 팀 관리 |
| 버튼 | 7일 무료 체험(레드) | 7일 무료 체험(테두리) |

- 아래 작은 글: 부가세 별도 · 7일 무료 후 자동결제 · 언제든 해지

### ⑧ 자주 묻는 질문 (접고 펴는 6개, 첫 항목만 펼침)
1. 설치해야 하나요? — 아니요. 브라우저로 바로 쓰고, 홈 화면에 추가하면 앱처럼 열립니다.
2. 어떤 기기에서 되나요? — 폰에 맞춰 만들었고, 태블릿·PC에서도 그대로 열립니다.
3. AI가 대신 팔아주나요? — 아니요. 관찰은 트레이너가, 근거 정리는 AI가 맡습니다.
4. 회원 정보는 안전한가요? — 계정별로 데이터가 분리되고, 회원은 본인 것만 봅니다.
5. 혼자 하는데도 되나요? — 네. 솔로 플랜으로 쓰고 급여·실적도 본인 기준으로 계산됩니다.
6. 의료·재활 목적인가요? — 아니요. 운동 지도·세일즈·회원관리 도구입니다.

### ⑨ 만든 사람 + 마무리
- **트레이너 경력 10년. 팀장·관리자까지 다 해본 사람이** / **답답해서 직접 만들었습니다.**(레드 글자)
- 한 줄: 어플·노션·스프레드시트를 다 써봤지만 타이핑은 그대로였습니다. 수업 밖 업무를 전부 여기에 녹였습니다.
- 제목: **오늘 수업 끝나고** / **바로 써보세요.**
- 버튼: 7일 무료로 시작 → / 작은 글: 월 59,000원부터

### ⑩ 푸터 (연회색)
- 심볼 + 워드마크, "오직 트레이너는 운동 지도·세일즈·회원관리 도구입니다. 의료기관이 아니며 치료·진단을 제공하지 않습니다."

- 사업자 정보 블록(상호·대표·사업자등록번호·통신판매업·주소·연락처, 약관 링크) — **법적 필수, 빼지 말 것.** 자리만 잡아두면 된다.

## 7. 실제 앱 화면 자리

실제 사이트에서는 각 자리에 **실제 앱이 움직이는 모션 데모**가 들어간다(폰 프레임 포함, 원본 크기 524×766, 일부는 폰이 가로로 돌아감).
Claude Design 캔버스에서는 이걸 직접 넣을 수 없으니:
- **첨부한 스크린샷이 있으면 그걸 쓴다.**
- 없으면 **비율 524:766의 자리표시 상자**에 어떤 화면인지 라벨만 단다(예: "운동일지 실제 화면"). 가짜 앱 화면을 그려 넣지 않는다.

## 8. 스크롤 효과 — 이번 작업의 핵심

짐워크처럼 **스크롤해서 화면에 들어오는 순간 나타나는 효과**.

| 항목 | 값 |
|---|---|
| 움직임 | 투명 → 선명 + 아래에서 위로 24px 떠오름 |
| 시간·곡선 | 0.6초 · 빠르게 시작해 부드럽게 멈춤(ease-out) |
| 시작 시점 | 요소가 화면 아래 10% 지점에 들어올 때 |
| 순서(기능 행) | 제목 → 흐름 칩 → 효과 3줄 → 앱 화면 순으로 0.1~0.12초씩 차이 ("설명 → 화면"으로 읽히게) |
| 숫자 띠 | 세 숫자가 차례로(선택: 0에서 목표값으로 세어 올라가기) |
| 한 번만 | 위로 다시 올렸다 내려와도 다시 재생하지 않음 |
| 첫 화면 | **효과 없음** — 처음부터 보여야 함 |
| 동작 줄이기 설정 | 기기에서 '동작 줄이기'를 켠 사람에게는 효과 없이 바로 보임 |
| 금지 | 튕김(바운스)·회전·크게 확대 같은 과한 효과 |

Claude Design 캔버스에서 실제로 움직이는 프로토타입으로 보여주면 가장 좋다(대표가 느낌을 보고 결정).

## 9. 반응형 · 사용성

- **폰 375px:** 한 열. 글은 가운데 정렬, 효과 3줄 목록만 왼쪽 정렬. 가로 스크롤 생기면 안 됨.
- **PC 1280px:** 내용 최대 폭 1120px. 기능 행은 글 | 앱 화면 2열, 행마다 좌우 교차.
- 누르는 모든 것은 **높이 44px 이상**(주 버튼은 52px).
- 글자 대비 **4.5:1 이상**(검정 구간의 보조 글자 포함).
- 버튼·링크는 실제 버튼/링크로(키보드로 이동 가능하게).

## 10. 산출물로 받고 싶은 것

1. **폰(375) 아트보드 1개 + PC(1280) 아트보드 1개** — 위 구성 전체.
2. 스크롤 효과가 보이는 **움직이는 프로토타입**(가능하면).
3. 섹션 구조와 카피는 위 순서를 유지 — 그래야 코드로 그대로 옮길 수 있다. 구조를 바꾸자는 제안은 **별도 시안으로** 따로 보여줄 것.
4. 위 색 값과 Pretendard만 사용 — 새 색·새 글꼴을 쓰면 코드로 옮길 때 다시 맞춰야 한다.

확정되면 Claude Code에 "Claude Design 시안대로 랜딩 반영해줘"라고 요청 → `app/lp/page.jsx`에 적용.
