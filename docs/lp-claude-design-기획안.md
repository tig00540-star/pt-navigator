## 3. 공통 — 브랜드 값

**이름:** 오직 트레이너 — 워드마크 "오직"(먹색) + "트레이너"(레드). 심볼은 원 안에 위를 가리키는 레드 삼각형 + 가운데 점.

| 역할 | 값 |
|---|---|
| 페이지 배경(연회색) | `#f1f2f6` |
| 카드·흰 바탕 | `#ffffff` |
| 눌린 패널 | `#e8eaf0` |
| 구분선 | `#dfe2ea` / 진한 선 `#cbd2dd` |
| 본문(먹색) | `#13151b` |
| 보조 글자 | `#475569` |
| 흐린 글자 | `#5b6675` |
| 브랜드 레드(채움·버튼) | `#dc2626` |
| 레드 글자(흰 바탕 위) | `#b91c1c` |
| 레드 옅은 바탕 | `#fef2f2` |
| 먹색 구간 위 강조 | `#fca5a5` |

- 레드는 누르는 곳과 핵심 강조에만. 금액·성과를 초록으로 칠하지 않는다.
- 글꼴은 **Pretendard 한 벌**(굵기·자간으로만 위계). 제목 800~900 · 자간 -0.04em 안팎. 다른 글꼴 추가 금지.
- 한글은 단어 중간에서 끊기지 않게(`word-break: keep-all`).
- 용어: 센터 주인은 **대표**(원장·관리자 ❌) · 회원이 보는 화면은 **회원 전용 페이지**(회원앱 ❌) · 수업 기록은 **운동일지** · OT 후 등록 비율은 **등록률**.

## 4. 공통 — 절대 하지 말 것

- 그라데이션(모든 종류), 글로우, 유리 효과, 네온, 이모지
- 아이콘 + 제목 + 설명을 담은 **같은 크기 카드를 격자로 늘어놓는 구성**
- 카드 안에 카드 · 섹션마다 01/02/03 번호 · 크림색 배경 + 세리프 제목 · 튕기는 애니메이션
- **없는 증거를 지어내기** — 후기·고객사 로고·성과 수치·도입 센터 수. (베타라 확보된 것이 없다. 자리가 필요하면 `[실제 후기]`처럼 빈칸)
- 허위 긴급성("오늘만", 카운트다운) · 의료 표현(치료·교정·진단)
- **확인 안 된 기능을 약속하기** — 이 문서에 적힌 기능만 쓴다(기존 회원 데이터 일괄 가져오기 같은 건 없음).

## 5. 페이지 A — 트레이너용 (`onlytrainer.co.kr`)

> 카피는 현재 배포본 그대로. **바꾸고 싶으면 바꾼 곳을 따로 표시.** 단 ⑥ '대표님께'는 이번에 **짧게 줄인다**(센터용 페이지가 생기므로).

**① 헤더(고정)** — 심볼 + "오직 트레이너" · 전환 스위치 `트레이너용 | 센터 대표용`(§7) · PC 가운데: 기능 · 가격 · 자주 묻는 질문 · 오른쪽: "로그인" · **"무료로 시작"**(먹색)

**② 첫 화면** — **수업만 하세요.** / **나머지는 앱이 합니다.**(레드) · 한 줄: OT 준비부터 운동일지·재등록·정산까지, 트레이너의 수업 밖 업무를 앱이 맡습니다. · 버튼: **7일 무료로 시작 →**(레드) · 앱처럼 설치(테두리) · 작은 글: 설치 없이 폰에서 바로 · 7일 무료 체험 · ⚠️ 첫 화면은 스크롤 효과 없이 처음부터 보임.

**③ 숫자 띠(연회색)** — 30초 · 말로 남기는 운동일지 / 5분 · AI와 끝내는 OT 준비 / **0건**(레드) · 놓치는 재등록
> "0건"은 약속처럼 읽혀 대표가 고민 중. 대안이 있으면 제안.

**④ 왜** — **수업은 2시간,** / **수업 밖 업무는 4시간.**(레드) · 한 줄: 일지·상담 준비·재등록 챙기기. 실력이 아니라 시간을 먹는 일들을 앱에 넘기세요. · 전 → 후 4줄(전은 취소선, 후는 굵게 + 레드 화살표):
일지·기록에 매일 40분 → **말로 30초** / OT 준비는 매번 백지에서 → **AI가 대사·근거까지** / 재등록은 기억력에 의존 → **앱이 먼저 알림** / 회원이 늘수록 관리도 두 배 → **회원이 셀프로 관리**

**⑤ 기능 4개** — 각 행: 작은 라벨 · 제목 두 줄 · 흐름 칩(`A › B › C`, 마지막 칩만 먹색 채움 · **폰 폭에서 한 줄**) · 효과 3줄 · 앱 화면. PC는 글 | 화면을 행마다 좌우 교차.

| 라벨 | 제목 | 흐름 칩 | 효과 3줄 | 앱 화면 |
|---|---|---|---|---|
| 운동일지 | 쓰지 말고, / 말하세요. | 수업 › 말로 복기 › 회원에게 전송 | 운동별 무게·횟수·세트를 알아서 정리 / 회원에게 보낼 일지까지 한 번에 / 세션 차감·출석 기록도 자동 | 운동일지 |
| 신규 OT · 세일즈 | 세일즈 잘 모르겠으면, / 따라만 하세요. | OT 보고서 › 클로징 멘트 › 거절 대응 | 회원 정보로 만드는 맞춤 OT 진행 순서 / 수업 직전 3분, 바로 말할 클로징 멘트 / 가격·'생각해볼게요' 등 거절 5가지 대응 | 신규 OT |
| 재등록 | 재등록 시기, / 앱이 먼저 알려줘요. | 만료 임박 알림 › 변화 근거 › 제안까지 | 잔여가 줄어든 회원을 '오늘 챙길 것'에 먼저 / 인바디·운동일지로 그동안의 변화 정리 / 재등록 제안 멘트까지 준비 | 재등록 |
| 회원 전용 페이지 | 붙잡지 마세요. / 회원이 스스로 챙깁니다. | 링크 하나 › 기록 열람 › 출석 챌린지 | 설치 없이 링크로 여는 회원 전용 페이지 / 운동일지·인바디·변화 그래프를 회원이 직접 / 출석이 쌓이는 오운완 챌린지와 포상 | 회원 전용 페이지 |

그 아래: "그리고 수업 밖 나머지도" + 칩 — 급여 자동계산 · 스케줄·노쇼 · 운동 라이브러리 · 내 실적 리포트 · 센터 공지

**⑥ 센터를 운영하시나요? (먹색 띠 하나 — 짧게)** — 라벨: 센터 대표님께 · 제목: **센터 숫자를 한 화면에서.** · 한 줄: 매출·정산·등록과 이탈·트레이너별 성과를 대표 화면에서. · 버튼: **센터 대표용 페이지 보기 →**(흰 버튼) · 앱 화면 없음(센터용 페이지가 담당).

**⑦ 가격(연회색)** — 7일 무료로 먼저 써보세요. / 신규·재등록 **1건만 더** 나와도 회수됩니다. · 카드 2장(금액은 실제 결제 금액 — 바꾸지 말 것):

|---|---|---|
| 대상 | 개인 트레이너 1인 | 트레이너 3인 + 대표 1인 |
| 월 | **59,000원** (정가 79,000원 취소선 · 얼리버드) | **149,000원** (정가 199,000원 · 얼리버드) |
| 포함 | 1·2차 OT · 재등록 서포트 / 음성 운동일지 · AI 리포트 / **회원 전용 페이지 (성과 그래프·비포애프터)** / 실적 · 급여 자동계산 | 솔로 전체 포함 / **대표 대시보드 (매출·정산·등록·이탈)** / 트레이너 3인 좌석 + 대표 1인 / 트레이너 코칭 · 팀 관리 |

## 6. 페이지 B — 센터 대표용 (`onlytrainer.co.kr/center`) · 새로 만듦

> 대표는 **'트레이너를 감시하는 도구'**를 사는 게 아니라 **'트레이너가 먼저 편해지고, 그 결과가 숫자로 보이는 센터'**를 산다. 이 긴장을 ⑤에서 정면으로 푼다.
> 아래 카피는 초안이다 — 다듬어도 좋다(사실 관계는 바꾸지 말 것).

**① 헤더(고정)** — 트레이너용과 같은 헤더, 전환 스위치는 `센터 대표용`이 켜진 상태 · PC 가운데: 대표 화면 · 도입 방법 · 가격 · 자주 묻는 질문 · 오른쪽: "로그인" · **"도입 문의"**(먹색)

**② 첫 화면(먹색 바탕으로 시작해도 좋음 — 대표 화면 느낌)**
- 제목: **감으로 보던 센터를,** / **숫자로 봅니다.**
- 한 줄: 트레이너는 수업에만, 대표는 숫자로. 매출·정산·등록과 이탈을 한 화면에서.
- 버튼: **센터 도입 문의 →**(주) · 센터로 7일 무료 시작(보조)
- 작은 글: 트레이너 3인 + 대표 1인 · 7일 무료 체험

**③ 왜 — 대표의 늦은 깨달음 4줄(전 → 후)**
- 제목: **문제는 늘,** / **뒤늦게 보입니다.**
- 매출은 월말 정산 때야 안다 → **이달 매출·다음달 예상을 실시간으로**
- OT는 많은데 등록이 안 되는 이유를 모른다 → **어디서 새는지 단계별로**
- 회원이 떠난 뒤에야 안다 → **이탈 위험·만료 임박을 먼저**
- 트레이너 평가가 감에 의존한다 → **트레이너별 등록률·재등록률·수업 수**

**④ 대표 화면 기능 3개** — 각 행: 작은 라벨 · 제목 두 줄 · 효과 3줄 · 앱 화면(PC 좌우 교차)

| 라벨 | 제목 | 효과 3줄 | 앱 화면 |
|---|---|---|---|
| 오늘 챙길 것 | 아침에 열면, / 오늘 할 일부터. | 이탈 위험·재등록 대상 회원을 급한 순서로 / 오늘 신규 OT 예정과 명단 / 트레이너 코칭까지 담은 AI 운영 보고서 | 대표 '오늘 챙길 것' |
| 매출 · 정산 | 월말까지 기다리지 / 마세요. | 이달 매출 현황 — 목표·현재·달성률, 트레이너별 목표 / 다음달 예상 매출 / 정산 — PT·FC·기타 매출과 지출, 순이익을 센터 정산일 기준으로 | 대표 매출 |
| 등록 · 이탈 | 어디서 새는지, / 숫자로 보입니다. | 신규 OT → 1차 → 2차 → 등록, 단계별로 몇 명이 빠지는지 / 달마다 등록률 — 나아지고 있는지 / 이탈 위험·만료 임박 명단을 바로 펼쳐보기 | 대표 등록·이탈 |

그 아래: "운영도 손이 덜 가게" + 칩 — 트레이너 초대 · 회원 등록·배정 · 회원 인계(잔여 세션 이월) · 급여 자동계산·확정 · 필수 공지 · 스케줄·노쇼

**⑤ 트레이너가 먼저 좋아하는 앱 (트레이너용 페이지와 연결되는 구간)**
- 제목: **트레이너가 편해야,** / **센터 숫자가 오릅니다.**
- 한 줄: 감시 도구가 아닙니다. 트레이너의 수업 밖 업무를 덜어주는 앱이고, 대표 화면의 숫자는 그 결과로 쌓입니다.
- 3줄(트레이너 쪽 효과 요약): 말로 30초면 운동일지 끝 / OT 들어가기 전 3분, 바로 말할 클로징 멘트 / 재등록 시기를 앱이 먼저 알림
- 버튼: **트레이너용 페이지 보기 →**(테두리)

**⑥ 도입은 이렇게 (3단계 — 실제 흐름 그대로)**
1. 센터 계정 만들기 — 7일 무료로 시작
2. 트레이너 초대 — 최대 3명, 이메일로 계정 발급
3. 회원 등록·배정 — 그날부터 숫자가 쌓입니다
> 번호는 여기서만 쓴다(순서 자체가 정보라서).

**⑦ 가격** — 센터 플랜 카드 1장(크게): **149,000원/월**(정가 199,000원 취소선 · 얼리버드) · 트레이너 3인 + 대표 1인 · 포함: 트레이너 앱 전체(OT·운동일지·재등록·회원 전용 페이지) / **대표 대시보드 (매출·정산·등록·이탈)** / 트레이너 3인 좌석 + 대표 1인 / 트레이너 코칭 · 팀 관리 · 버튼: **센터 도입 문의**(주) · 센터로 7일 무료 시작(보조) · 작은 글: 부가세 별도 · 7일 무료 후 자동결제 · 언제든 해지 · 트레이너가 더 필요하면 문의해 주세요.

**⑧ 자주 묻는 질문(센터용)**
1. 트레이너가 4명 이상이면요? — 문의해 주세요. 센터 규모에 맞춰 안내드립니다.
2. 트레이너들이 싫어하지 않을까요? — 트레이너의 일지·OT 준비·재등록 챙기기를 덜어주는 앱이라, 트레이너가 먼저 편해집니다.
3. 다른 센터와 데이터가 섞이지 않나요? — 센터별로 완전히 분리되고, 매출·정산 화면은 대표만 봅니다.
4. 기존 PT 회원은 어떻게 옮기나요? — 회원을 등록할 때 '인계받은 PT'로 남은 세션을 이어서 등록할 수 있습니다.
5. 결제는 어떻게 되나요? — 7일 무료 후 월 자동결제이고, 언제든 해지할 수 있습니다.

**⑨ 마무리** — 제목: **이번 달 숫자부터,** / **같이 보시죠.** · 버튼: 센터 도입 문의 → · 보조: 센터로 7일 무료 시작

## 7. 두 페이지 연결 규칙

| 위치 | 트레이너용 | 센터 대표용 |
|---|---|---|
| 헤더 전환 스위치 | `트레이너용`(켜짐) \| `센터 대표용` | `트레이너용` \| `센터 대표용`(켜짐) |
| 본문 다리 | ⑥ "센터를 운영하시나요?" → 센터용 | ⑤ "트레이너가 먼저 좋아하는 앱" → 트레이너용 |
| 가격 | 센터 카드 버튼 = "센터 자세히 보기" → 센터용 | — |
| 푸터 | "센터 대표용 페이지" 링크 | "트레이너용 페이지" 링크 |

- 전환 스위치는 **스크롤해도 보이게**(헤더 고정). 폰에서도 두 칸이 한눈에 보이고, 각 칸은 누르는 영역 44px 이상.
- 스위치는 페이지 이동(링크)이다 — 같은 페이지 안 탭이 아님.
- 두 페이지는 **같은 브랜드로 보여야** 한다: 같은 헤더·글꼴·색·카드·버튼. 센터용만 먹색 구간이 더 많을 뿐.

## 8. 공통 푸터

- 심볼 + 워드마크 · "오직 트레이너는 운동 지도·세일즈·회원관리 도구입니다. 의료기관이 아니며 치료·진단을 제공하지 않습니다."
- 링크: 트레이너용 · 센터 대표용 · 가격 · 자주 묻는 질문 · 설치 안내
- 사업자 정보 블록(상호·대표·사업자등록번호·통신판매업·주소·연락처, 약관 링크) — **법적 필수, 빼지 말 것.** 자리만 잡아두면 된다.

## 10. 스크롤 효과 — 두 페이지 공통 · 이번 작업의 핵심

| 항목 | 값 |
|---|---|
| 움직임 | 투명 → 선명 + 아래에서 위로 24px 떠오름 |
| 시간·곡선 | 0.6초 · 빠르게 시작해 부드럽게 멈춤(ease-out) |
| 시작 시점 | 요소가 화면 아래 10% 지점에 들어올 때 |
| 순서(기능 행) | 제목 → 칩 → 효과 3줄 → 앱 화면, 0.1~0.12초씩 차이("설명 → 화면"으로 읽히게) |
| 숫자 띠 | 세 숫자가 차례로(선택: 0에서 목표값까지 세어 올라가기) |
| 한 번만 | 다시 스크롤해도 재생하지 않음 |
| 첫 화면 | **효과 없음** — 처음부터 보여야 함 |
| 동작 줄이기 설정 | 효과 없이 바로 보임 |
| 금지 | 튕김·회전·크게 확대 같은 과한 효과 |

가능하면 **실제로 움직이는 프로토타입**으로 보여줄 것(대표가 느낌을 보고 결정).

## 11. 반응형 · 사용성

- **폰 375px:** 한 열. 글은 가운데 정렬, 체크 목록만 왼쪽 정렬. 가로 스크롤 금지.
- **PC 1280px:** 내용 최대 폭 1120px. 기능 행은 글 | 앱 화면 2열, 행마다 좌우 교차.
- 누르는 모든 것은 **높이 44px 이상**(주 버튼 52px) · 글자 대비 **4.5:1 이상**(먹색 구간 포함) · 버튼·링크는 실제 버튼/링크로.

## 12. 받고 싶은 산출물

1. 트레이너용 **폰 + PC** 아트보드, 센터 대표용 **폰 + PC** 아트보드 — 총 4개.
2. 스크롤 효과와 **두 페이지 사이 이동(전환 스위치)**이 되는 프로토타입(가능하면).
3. 섹션 순서·카피는 이 문서 순서 유지 — 코드로 그대로 옮기기 위해. 구조 변경 제안은 **별도 시안**으로.
4. 위 색 값과 Pretendard만 — 새 색·새 글꼴은 코드로 옮길 때 다시 맞춰야 한다.

확정되면 Claude Code에 "Claude Design 시안대로 랜딩 두 개 반영해줘"라고 요청한다.
